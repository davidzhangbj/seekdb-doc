# SeekDB MCP Server

## Background information

AI tools are evolving rapidly, with graphical tools like Cursor, Windsurf, Trae, and command-line tools such as Claude Code, Gemini CLI, and Qwen Code. Enhanced by agent-based architectures, these tools have become extremely powerful. However, there is still a missing “bridge” between AI tools and databases—AI tools cannot directly access databases. The MCP protocol serves as this bridge. OceanBase MCP Server uses the MCP protocol to interact with AI tools, enabling them to read data directly from databases. <!-- (OceanBase MCP Server -> SeekDB MCP Server) -->

Traditional data analysis tasks such as “user data analysis,” “product analysis,” “order analysis,” and “user behavior analysis” typically require developers to build backend platforms for data retrieval and frontend pages for data display. Even with BI analysis tools, users often need some knowledge of SQL. Data is merely presented, and understanding the logic behind it or driving business changes still relies heavily on the insights of data analysts.

With the integration of AI tools, MCP, and LLMs, the landscape of data analysis is changing. Analysts no longer need developers’ involvement or SQL expertise. They simply describe their requirements to these AI tools and receive the desired results—beautiful charts and preliminary data insights—automatically.

## Functional Architecture

### Core Toolkit

SeekDB MCP Server provides standardized interfaces, allowing AI tools to directly invoke database functionalities:

| Tool Name                   | Description |
|-----------------------------|-------------|
| `execute_sql`               | Executes any SQL statement (`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `DDL`, etc.). |
| `get_ob_ash_report`         | Retrieves SeekDB Active Session History (ASH) reports for performance diagnostics. |
| `get_current_time`          | Returns the current time of the SeekDB cluster. |
| `search_oceanbase_document` | Searches official SeekDB documentation (experimental feature). |
| `oceanbase_text_search`     | Performs full-text search for documents in SeekDB database tables. |
| `oceanbase_vector_search`   | Executes vector similarity searches within SeekDB database tables. |
| `oceanbase_hybrid_search`   | Conducts hybrid searches, combining relational filtering with vector search. |
| `ob_memory_query`           | Retrieves historical conversation records from the AI memory system using semantic search. (AI Memory System Tool) |
| `ob_memory_insert`          | Automatically captures and stores important conversation content to build a knowledge base. (AI Memory System Tool) |
| `ob_memory_delete`          | Deletes outdated or redundant conversation memories. (AI Memory System Tool) |
| `ob_memory_update`          | Updates or evolves memory content based on new information. (AI Memory System Tool) |

### Resource Endpoints

The resource endpoints exposed via the MCP protocol can be directly invoked by AI tools:

| Resource Path                  | Description |
|--------------------------------|-------------|
| `oceanbase://tables`           | Lists all tables in the database. |
| `oceanbase://sample/{table}`   | Retrieves sample data (first 100 rows) from the specified table. `{table}` can be dynamically replaced with the table name. |

## Integration Steps

### Step 1: Obtain Database Connection Information

Contact your OceanBase database administrator to get the connection string, for example:

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter Description:**

* `$host`: IP address for connecting to the SeekDB database.
* `$port`: Connection port for SeekDB. Default is `2881`.
* `$database_name`: Name of the database to access.
* `$user_name`: Account for connecting to the instance. Default is `root`.
* `$password`: Account password. Default is empty.

**Example:**

```shell
obclient -hxxx.xxx.xxx.xxx -P2881 -uroot -p****** -Dtest
```

### Step 2: Install Python Dependencies

#### Environment Preparation

1. Install the uv package manager.

   * For macOS/Linux, run:

       ```shell
       curl -LsSf https://astral.sh/uv/install.sh | sh
       ```

   * For Windows, run:

       ```shell
       irm https://astral.sh/uv/install.ps1 | iex
       ```

   * Alternatively, you can install uv using pip:

       ```shell
       pip install uv
       ```

2. Verify the installation:

    ```shell
    uv --version
    ```

#### Install OceanBase MCP Server

1. Choose a directory and create a virtual environment:

    ```shell
    uv venv
    ```

2. Activate the virtual environment:

    ```shell
    source .venv/bin/activate
    ```

3. Install OceanBase MCP Server:

    ```shell
    uv pip install oceanbase-mcp
    ```

### Step 3: Configure the MCP Server Environment

1. Create a `.env` file:

    ```shell
    cat > .env <<EOF
    OB_HOST=127.0.0.1
    OB_PORT=2881
    OB_USER=root  # Example: MySQL tenant user
    OB_PASSWORD=your_password
    OB_DATABASE=test
    EOF
    ```

2. Start the MCP Server:

    ```shell
    uv run oceanbase_mcp_server \
        --transport sse \           # Supports stdio/streamable-http/sse modes
        --host 0.0.0.0 \            # Allows external access, use 127.0.0.1 for local access only
        --port 8000                 # Custom port (update later configs if changed)
    ```

### Step 4: Configure Cursor to Connect to MCP Server

1. Open Cursor’s settings: Click the gear icon in the top right → Select MCP → Click New MCP Server.

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/1.0.png)

2. Edit the `mcp.json` configuration:

    ```shell
    {
      "mcpServers": {
        "ob-sse": {
          "autoApprove": [],
          "disabled": false,       # Must be set to false to enable the service
          "timeout": 60,
          "type": "sse",
          "url": "http://127.0.0.1:8000/sse"  # Should match the port in Step 3
        }
      }
    }
    ```

3. Verify the connection.

    After saving, return to the MCP page to see the newly added MCP server.

4. Once added, asking questions in the Chat window will automatically use MCP tools via Cursor.

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/2.png)

### User Data Analysis

1. Enter the instruction:

    ```shell
    Please analyze the user data and show the distribution of user ages and cities.
    ```

2. Cursor’s execution flow:

    1. Cursor calls `execute_sql` to run an aggregation query:

        ```sql
        SELECT age, city, COUNT(*) AS user_count  
        FROM users  
        GROUP BY age, city;  
        ```

    2. Automatically generates a structured analysis result.
