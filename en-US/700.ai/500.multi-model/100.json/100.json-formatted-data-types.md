# Overview of the JSON data type

OceanBase Database supports the JSON (JavaScript Object Notation) data type that conforms to the RFC 7159 standard. You can store semi-structured JSON data in a table and access and modify data in a JSON document.

The JSON data type has the following advantages:

* The JSON documents stored in a JSON column are automatically validated. An error is returned if a JSON document is invalid.

* The JSON documents stored in a JSON column can be converted to a format that facilitates quick reading and access. When a server must read a JSON value stored in binary format, it does not need to parse the value from text.

* Semi-structured encoding is supported, which further reduces storage costs. A JSON document can be split into multiple subcolumns and each subcolumn can be encoded separately to improve the compression rate and reduce the storage space required for the JSON document. For more information about how to use this feature, see [Create a JSON value](200.create-a-json-value.md) and [Semi-structured encoding](600.json-semi-struct.md).
