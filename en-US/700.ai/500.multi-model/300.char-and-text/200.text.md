# TEXT type

The `TEXT` type is used to store all types of text data.

There are four types of text: `TINYTEXT`, `TEXT`, `MEDIUMTEXT`, and `LONGTEXT`. They correspond to the four `BLOB` types and have the same maximum length and storage requirements.

`TEXT` values are treated as non-binary strings. They use character sets other than binary and are sorted and compared based on the collation rules of their respective character sets.

When strict SQL mode is not enabled, if a value assigned to a `TEXT` column exceeds the column's maximum length, the excess part will be truncated and an alert will be generated. In strict SQL mode, if the truncated part contains non-space characters, an error (not an alert) will occur, and the insertion will be prohibited. Regardless of the SQL mode, truncating trailing spaces in a `TEXT` column will always generate an alert.

## TINYTEXT

`TINYTEXT` is a `TEXT` type with a maximum length of 255 bytes.

The syntax for `TINYTEXT` is:

```sql
TINYTEXT [CHARACTER SET charset_name] [COLLATE collation_name]
```

`CHARACTER SET` specifies the character set. You can also use the `COLLATE` attribute along with other attributes to specify the collation rule for the character set. If you specify the binary attribute of `CHARACTER SET`, the column will be created as a corresponding binary string data type, and `TEXT` will become `BLOB`.

## TEXT

The maximum length of a `TEXT` column is 65,535 bytes.

You can optionally specify a length `M` for the `TEXT` type. The syntax is:

```sql
TEXT[(M)] [CHARACTER SET charset_name] [COLLATE collation_name]
```

`CHARACTER SET` specifies the character set. You can also use the `COLLATE` attribute along with other attributes to specify the collation rule for the character set. If you specify the binary attribute of `CHARACTER SET`, the column will be created as a corresponding binary string data type, and `TEXT` will become `BLOB`.

## MEDIUMTEXT

`MEDIUMTEXT` is a `TEXT` type with a maximum length of 16,777,215 bytes.

The syntax for `MEDIUMTEXT` is:

```sql
MEDIUMTEXT [CHARACTER SET charset_name] [COLLATE collation_name]
```

`CHARACTER SET` specifies the character set. You can also use the `COLLATE` attribute along with any other attributes to specify the collation rule for the character set. If you specify the binary attribute of `CHARACTER SET`, the column will be created as a corresponding binary string data type, and `TEXT` will become `BLOB`.

Additionally, SeekDB supports the extended type `LONG`, but we recommend using `MEDIUMTEXT` instead.

## LONGTEXT

`LONGTEXT` is a `TEXT` type with a maximum length of 536,870,910 bytes. The effective maximum length of a `LONGTEXT` column also depends on the maximum packet size configured in the client/server protocol and the available memory.

The syntax for `LONGTEXT` is:

```sql
LONGTEXT [CHARACTER SET charset_name] [COLLATE collation_name]
```

`CHARACTER SET` specifies the character set. You can also use the `COLLATE` attribute along with other attributes to specify the collation rule for the character set. If you specify the binary attribute of `CHARACTER SET`, the column will be created as a corresponding binary string data type, and `TEXT` will become `BLOB`.
