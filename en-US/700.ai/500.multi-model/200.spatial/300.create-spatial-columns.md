# Create a spatial column

SeekDB allows you to use the `CREATE TABLE` or `ALTER TABLE` statement to create a spatial column.

Use the `CREATE TABLE` statement to create a table with a spatial column. The syntax is as follows:

```sql
CREATE TABLE geom (g GEOMETRY);
```

Use the `ALTER TABLE` statement to add or drop a spatial column from an existing table. The syntax is as follows:

```sql
ALTER TABLE geom ADD pt POINT;
ALTER TABLE geom DROP pt;
```

Here is an example:

```sql
obclient> CREATE TABLE geom (
    p POINT SRID 0,
    g GEOMETRY NOT NULL SRID 4326
);
Query OK, 0 rows affected
```

The following constraints apply to spatial columns:

* When you define a spatial column, you can explicitly specify the SRID. If no SRID is specified for the column, the optimizer does not select spatial indexes during queries. However, insertions and updates still generate index records.

* After defining a spatial column with the `NOT NULL` constraint and specifying the SRID, you can define a spatial index on the column. In other words, only columns with defined SRIDs can have spatial indexes.

* If you define an SRID for a spatial column, inserting objects with different SRIDs will result in errors.

The following constraints apply to the `SRID` clause:

* You must explicitly specify the `SRID` for a spatial column.

* All objects in the column must have the same SRID.
