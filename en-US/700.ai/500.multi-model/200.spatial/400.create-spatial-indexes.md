# Create a spatial index

SeekDB allows you to create a spatial index using the `SPATIAL` keyword. When creating a table, the column for the spatial index must be declared as `NOT NULL`. You can create a spatial index on stored (STORED) generated columns but not on virtual (VIRTUAL) generated columns.

## Constraints

* The column definition for creating a spatial index must include the `NOT NULL` constraint.
* The column with a spatial index must have an SRID defined. Otherwise, the spatial index will not be effective during queries.
* If you create a spatial index on a STORED generated column, the DDL operation must explicitly specify the `STORED` keyword when creating the column. If neither `VIRTUAL` nor `STORED` is specified, a VIRTUAL generated column is created by default.
* After an index is created, comparisons use the coordinate system corresponding to the SRID defined in the column's definition. Spatial indexes store the Minimum Bounding Rectangles (MBRs) of geometry objects, and MBR comparisons also depend on the SRID.

## Preparation

Before using GIS features, configure GIS metadata. After connecting to the server, execute the following command to import the `default_srs_data_mysql.sql` file into the database:

```shell
-- module specifies the module to import.
-- infile specifies the relative path to the SQL file.
ALTER SYSTEM LOAD MODULE DATA module=gis infile = 'etc/default_srs_data_mysql.sql';
```

For specific syntax details, see [LOAD MODULE DATA](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980607).

The following result indicates that the data file was successfully imported:

```shell
Query OK, 0 rows affected
```

## Examples

Here are examples of how to create a spatial index on a regular column:

* Using `CREATE TABLE`:

```sql
CREATE TABLE geom (g GEOMETRY NOT NULL SRID 4326, SPATIAL INDEX(g));
```

* Using `ALTER TABLE`:

```sql
CREATE TABLE geom (g GEOMETRY NOT NULL SRID 4326);
ALTER TABLE geom ADD SPATIAL INDEX(g);
```

* Using `CREATE INDEX`:

```sql
CREATE TABLE geom (g GEOMETRY NOT NULL SRID 4326);
CREATE SPATIAL INDEX g ON geom (g);
```

Here are examples of how to drop a spatial index:

* Using `ALTER TABLE`:

```sql
ALTER TABLE geom DROP INDEX g;
```

* Using `DROP INDEX`:

```sql
DROP INDEX g ON geom;
```
