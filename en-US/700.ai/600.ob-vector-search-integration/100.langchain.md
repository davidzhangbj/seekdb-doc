# Integrate SeekDB with LangChain

SeekDB provides capabilities for storing vector types, indexing vectors, and retrieving embedding vectors. You can store the vectorized data in SeekDB for retrieval in subsequent steps.

LangChain is a framework for developing applications driven by language models. It enables applications to:

* Be context-aware: Connect language models to sources of context (such as prompts, a few examples, and the content that needs to be responded to).
* Perform reasoning: Rely on language models for reasoning (such as how to answer based on the provided context or what actions to take).

This tutorial demonstrates how to integrate the [vector search feature](../100.vector-search/100.vector-search-overview/100.vector-search-intro.md) of SeekDB, [Qwen](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000001579715), and [LangChain](https://python.langchain.com/) using the Qwen API to implement document question answering.

## Prerequisites

* You have deployed the SeekDB database.
* You have a usable MySQL database and account in your environment, and you have granted read and write permissions to the database account.
* You have installed Python 3.9 or later.
* You have installed the dependencies.

    ```shell
    python3 -m pip install -U langchain-oceanbase
    python3 -m pip install langchain_community
    python3 -m pip install dashscope
    ```

* You can set the `ob_vector_memory_limit_percentage` parameter to enable vector retrieval. We recommend keeping it at the default value of `0` (adaptive mode). For more precise settings, please refer to the relevant configuration documentation.

## Step 1: Obtain the database connection information

Contact the deployment personnel or administrator of the SeekDB database to obtain the corresponding database connection string. For example:

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: The IP address for connecting to the SeekDB database.
* `$port`: The port for connecting to the SeekDB database. The default value is `2881`, which can be customized during deployment.
* `$database_name`: The name of the database to access.

## Step 2: Build your AI assistant

### Set the DashScope API key environment variable

Obtain your [DashScope API key](https://help.aliyun.com/zh/model-studio/developer-reference/get-api-key) and [configure it in the environment variables](https://help.aliyun.com/zh/model-studio/developer-reference/configure-api-key-through-environment-variables).

```shell
export DASHSCOPE_API_KEY="YOUR_DASHSCOPE_API_KEY"
```

### Load and split the documents

Download the sample data and split it into chunks of approximately 1000 characters using the `CharacterTextSplitter`.

```python
from langchain_community.document_loaders import TextLoader
from langchain_community.embeddings import DashScopeEmbeddings
from langchain_text_splitters import CharacterTextSplitter
from langchain_oceanbase.vectorstores import OceanbaseVectorStore
import os
import requests

DASHSCOPE_API = os.environ.get("DASHSCOPE_API_KEY", "")
embeddings = DashScopeEmbeddings(
    model="text-embedding-v1", dashscope_api_key=DASHSCOPE_API
)

url = "https://raw.githubusercontent.com/GITHUBear/langchain/refs/heads/master/docs/docs/how_to/state_of_the_union.txt"
res = requests.get(url)
with open("state_of_the_union.txt", "w") as f:
    f.write(res.text)

loader = TextLoader('./state_of_the_union.txt')

documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)
```

### Insert the data into SeekDB

```python
connection_args = {
    "host": "127.0.0.1",
    "port": "2881",
    "user": "root@sun",
    "password": "",
    "db_name": "test",
}
DEMO_TABLE_NAME = "demo_ann"
ob = OceanbaseVectorStore(
    embedding_function=embeddings,
    table_name=DEMO_TABLE_NAME,
    connection_args=connection_args,
    drop_old=True,
    normalize=True,
)
res = ob.add_documents(documents=docs)
```

### Vector search

This step shows how to query `“What did the president say about Ketanji Brown Jackson”` from the document `state_of_the_union.txt`.

```python
query = "What did the president say about Ketanji Brown Jackson"
docs_with_score = ob.similarity_search_with_score(query, k=3)

for doc, score in docs_with_score:
    print("-" * 80)
    print("Score: ", score)
    print(doc.page_content)
    print("-" * 80)
```
