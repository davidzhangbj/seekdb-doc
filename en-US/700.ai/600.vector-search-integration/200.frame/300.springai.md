# Integrate SeekDB Vector with Spring AI Alibaba

SeekDB supports vector type storage, vector indexing, and embedding vector retrieval. You can store vectorized data in SeekDB for subsequent retrieval.

Spring AI Alibaba is an open-source project based on Spring AI, serving as a best practice for developing Java AI applications using Alibaba Cloud's Tongyi series models and services. It simplifies the AI application development process and adapts to cloud-native infrastructure, enabling developers to quickly build AI applications.

This topic will demonstrate how to integrate Spring AI Alibaba with SeekDB's vector retrieval capabilities to implement data import and similarity search. By configuring vector storage and retrieval services, developers can easily build AI scenarios based on SeekDB, supporting advanced features such as text similarity search and content recommendation.

## Prerequisites

* You have deployed SeekDB.

* Download [JDK 17+](https://www.oracle.com/java/technologies/downloads/#java17). Make sure that you have installed Java 17 and configured the environment variables.

* Download [Maven](https://dlcdn.apache.org/maven/). Make sure that you have installed Maven 3.6+ to build the project and manage dependencies.

* Download [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) or [Eclipse](https://www.eclipse.org/downloads/). Choose the appropriate version for your operating system and install it.

## Step 1: Obtain database connection information

Contact the SeekDB deployment personnel or administrator to obtain the database connection string. For example:

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: the IP address for connecting to SeekDB.
* `$port`: the port for connecting to SeekDB. The default value is `2881`.
* `$database_name`: the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user used for the connection must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> permissions on the database. </p>
    </main>

* `$user_name`: the database account.
* `$password`: the password of the account.

## Step 2: Create a Maven project

Maven is the project management and build tool used in this topic. In this step, you create a Maven project and add project dependencies by configuring the `pom.xml` file.

### Create a project

1. Run the Maven command to create a project.

    ```shell
    mvn archetype:generate -DgroupId=com.alibaba.cloud.ai.example -DartifactId=vector-oceanbase-example -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false
    ```

2. Go to the project directory.

    ```shell
    cd vector-oceanbase-example
    ```

## Step 3: Configure the SeekDB connection information

In this step, you configure the `application.yml` file to add the SeekDB connection information.

Create the `application.yml` file in the `src/main/resources` directory of the project and add the following content:

```yaml
server:
  port: 8080

spring:
  application:
    name: oceanbase-example
  ai:
    dashscope:
      api-key: ${DASHSCOPE_API_KEY}  # Replace with your DashScope API Key.
    vectorstore:
      oceanbase:
        enabled: true
        url: jdbc:oceanbase://xxx:xxx/xxx  # SeekDB connection URL.
        username: xxx                     # SeekDB username.
        password: xxx                     # SeekDB password.
        tableName: vector_table           # Name of the vector table (automatically created).
        defaultTopK: 2                    # Number of similar results to return by default.
        defaultSimilarityThreshold: 0.8   # Similarity threshold (0~1, the smaller the value, the more similar).
```

## Step 4: Create the main application class and controller

Create the start class and controller class for the Spring Boot application to implement data import and similarity search.

### Create the application start class

In the `src/main/java/com/alibaba/cloud/ai/example/vector` directory, create a `OceanBaseApplication.java` file and add the following content:

```java
package com.alibaba.cloud.ai.example.vector;  // The package name must match the directory structure

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication  // Enable Spring Boot auto-configuration
public class OceanBaseApplication {
    public static void main(String[] args) {
        SpringApplication.run(OceanBaseApplication.class, args);  // Start the Spring Boot application
    }
}
```

The sample code is the core start class of the project, used to start the Spring Boot application.

### Create the vector storage controller

In the `src/main/java/com/alibaba/cloud/ai/example/vector` directory, create a `OceanBaseController.java` file and add the following content:

```java
package com.alibaba.cloud.ai.example.vector.controller;  // The package name must match the directory structure

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

import com.alibaba.cloud.ai.vectorstore.oceanbase.OceanBaseVectorStore;

@RestController  // Mark as a REST controller
@RequestMapping("/oceanbase")  // Set the base path to /oceanbase
public class OceanBaseController {

    private static final Logger logger = LoggerFactory.getLogger(OceanBaseController.class);  // Logger

    @Autowired  // Automatically inject the OceanBase vector storage service
    private OceanBaseVectorStore oceanBaseVectorStore;

    // Data import interface
    @GetMapping("/import")
    public void importData() {
        logger.info("Start importing data");

        // Create sample data
        HashMap<String, Object> map = new HashMap<>();
        map.put("id", "12345");
        map.put("year", "2025");
        map.put("name", "yingzi");

        // Create a list containing three documents
        List<Document> documents = List.of(
            new Document("The World is Big and Salvation Lurks Around the Corner"),
            new Document("You walk forward facing the past and you turn back toward the future.", Map.of("year", 2024)),
            new Document("Spring AI rocks!! Spring AI rocks!! Spring AI rocks!! Spring AI rocks!! Spring AI rocks!!", map)
        );

        // Add the documents to the vector store
        oceanBaseVectorStore.add(documents);
    }

    // Similarity search interface
    @GetMapping("/search")
    public List<Document> search() {
        logger.info("Start searching data");

        // Perform similarity search, query documents containing "Spring", and return the top 2 most similar results
        return oceanBaseVectorStore.similaritySearch(SearchRequest.builder()
                                                     .query("Spring")
                                                     .topK(2)
                                                     .build());
    }
}
```

## FAQ

### SeekDB connection failed

* Cause: The URL, username, or password is incorrect.
* Solution: Check the SeekDB configuration in `application.yml` and ensure that the database service has been started.

### Dependency conflicts

* Cause: Multiple Spring Boot versions are in conflict.
* Solution: Use `mvn dependency:tree` to view the dependency tree and exclude the conflicting versions.

### SNAPSHOT dependencies cannot be downloaded

* Cause: The SNAPSHOT repository is not configured.
* Solution: Ensure that the `sonatype-snapshots` repository has been added to `pom.xml`.
