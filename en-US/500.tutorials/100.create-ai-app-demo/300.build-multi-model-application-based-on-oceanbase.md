# Build a travel assistant based on seekdb's multimodal fusion

This topic demonstrates how to build a travel assistant using seekdb's multimodal fusion technology.

In this example, we will build a scenic spot recommendation application using seekdb's spatial data and vector search multimodal fusion. The application can use GIS and vector data mixed search to find relevant scenic spots, and combine with large model Agent workflow to realize a simple travel planning assistant.

## Technical principles

* Spatial data processing technology: GIS systems provide precise geographic positioning and optimal route planning.

* Vector data processing technology: Pre-trained models (BGE-m3) are used to convert unstructured data of attractions into vector representations, and the vector search capabilities of seekdb are used to efficiently process similarity searches.

* Large model agent technology: In the intelligent interaction layer, large model agent technology is used in conjunction with prompt engineering to understand user intent and support multi-turn dialogues, enabling the decomposition and planning of complex tasks. This enhances the system's interactive experience, allowing it to accurately understand your needs and provide personalized services.

* Content-based recommendation algorithm: A combination of collaborative filtering and content-based recommendation algorithms, incorporating contextual information such as season and reviews, to achieve personalized recommendations.

## Concepts

:::collapse

* Multi-modal fusion: Multi-modal fusion is a key capability of seekdb. In this context, multi-modal fusion primarily refers to multi-modal data mixed search technology. seekdb supports the fusion query of vector data, spatial data, document data, and scalar data. Based on the support of vector indexes, spatial indexes, and full-text indexes, it provides higher-performance mixed search capabilities.

  ![Multi-modal fusion diagram](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/tutorial/AI/%E6%96%87%E6%97%85%E5%B0%8F%E5%8A%A9%E6%89%8B%E5%A4%9A%E6%A8%A1%E8%9E%8D%E5%90%88%E7%A4%BA%E6%84%8F%E5%9B%BE-1.jpg)

* LLM (Large Language Model): A large language model is a deep learning model trained on a large amount of text data. It can generate natural language text or understand the meaning of language text. Large language models can handle various natural language tasks, such as text classification, question-answering, and dialogue, serving as a crucial step towards achieving artificial intelligence.

:::

## Prerequisites

* You have deployed seekdb. For more information about deploying seekdb, see [Overview](../../400.guides/400.deploy/50.deploy-overview.md).

* You have created a database. For more information about creating a database, see [Create a database](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002013232).

* The vector search feature is enabled for the database. For more information about the vector search feature, see [Perform vector search using SQL](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002012934).

    ```shell
    obclient> ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
    ```

* (Recommended, not mandatory) Install [Python 3.10 or later](https://www.python.org/downloads/) and the corresponding [pip](https://pip.pypa.io/en/stable/installation/). If your machine has a low Python version, you can use Miniconda to create a new Python 3.10 or later environment. For more information, see [Miniconda installation guide](https://docs.anaconda.com/miniconda/install/).

    ```shell
    conda create -n obmms python=3.10 && conda activate obmms
    ```

* Install [Poetry](https://python-poetry.org/docs/). You can run the following command:

    ```shell
    python3 -m ensurepip
    python3 -m pip install poetry
    ```

* Install the corresponding Python packages. You can run the following command:

    ```shell
    pip install python-dotenv tqdm streamlit pyobvector==0.2.16
    ```

## Step 4: Build your tourism and cultural assistant

### Clone the project repository

1. Clone the latest project repository.

    ```shell
    git clone https://github.com/oceanbase-devhub/ob-multi-model-search-demo.git
    cd ob-multi-model-search-demo
    ```

2. Move the downloaded `archive` dataset ZIP file to the `ob-multi-model-search-demo` project folder, rename it to `citydata`, and extract it.

    ```shell
    # Please replace this with the actual path where the archive.zip file is saved.
    mv ./archive.zip ./citydata.zip
    unzip ./citydata.zip
    ```

### Install dependencies

In the project root directory, run the following command to install dependencies.

```shell
poetry install
```

### Set environment variables

Set environment variables in the `.env` file:

```shell
vim .env
```

You need to update the variables starting with `OB_` with your database connection information and manually add the following variables: Update `DASHSCOPE_API_KEY` with the API key obtained from the DashScope console, and update `AMAP_API_KEY` with the API key obtained from the Amap API service. Then, save the file.

```text
# The host address in the database connection string
OB_URL="******"   ## Format: IP:<Port>
OB_USER="******"  ## Username
OB_DB_NAME="******"  ## Database name
# The password in the database connection string
OB_PWD="******"
# The path to the SSL CA file in the database connection string (optional). If SSL link encryption is not required, remove this parameter.
OB_DB_SSL_CA_PATH="******"

# Manually add the LLM API key
DASHSCOPE_API_KEY="******"
# Manually add the Amap API key
AMAP_API_KEY="******"
```

### Import data

In this step, we will import the data from the downloaded dataset into seekdb.

<main id="notice" type='notice'>

## Troubleshooting

### Dependency installation issues

#### Poetry installation failed

If the `poetry install` command fails, you can try the following steps:

1. Update Poetry to the latest version:
   ```shell
   pip install --upgrade poetry
   ```

2. Clear Poetry cache:
   ```shell
   poetry cache clear --all pypi
   ```

3. Reinstall dependencies:
   ```shell
   poetry install --no-cache
   ```

### Environment configuration issues

#### Python environment not activated

<main id="notice" type='warning'>
  <h4>Important</h4>
  <p>Make sure you have activated the correct Python environment (such as the obmms conda environment) before installing dependencies.</p>
</main>

Make sure you have activated the correct conda environment:

```shell
conda activate obmms
```

#### Python version is incompatible

Make sure you are using Python 3.10 or later:

```shell
python --version
```

If the version is too low, please create a new environment:

```shell
conda create -n obmms python=3.10
conda activate obmms
```

### Database connection issues

If you encounter database connection issues, please check the following:

1. Whether the database connection information in the `.env` file is correct
2. Whether seekdb is running normally
3. Whether the network connection is normal
4. Whether the database user has sufficient privileges

### Other common issues

#### Port occupied

If a port is occupied when starting Streamlit, you can specify another port:

```shell
poetry run streamlit run ./ui.py --server.port 8502
```

#### Insufficient memory

If you encounter memory issues during data import, you can:

1. Reduce the amount of data imported in batches
2. Increase the system memory
3. Adjust the memory configuration of seekdb

#### API key issues

Make sure you have correctly configured the following:

1. Alibaba Cloud DashScope API key (DASHSCOPE_API_KEY)
2. Amap API key (AMAP_API_KEY)

You can configure the API keys in the `.env` file.
