# Build an image search application based on SeekDB

## Background information

In today's era of information explosion, users often need to quickly retrieve the information they need from massive amounts of data. For example, online literature databases, e-commerce platform product catalogs, and growing multimedia content libraries all require efficient retrieval systems to quickly locate content of interest to users. As data volumes continue to grow, traditional keyword-based retrieval methods can no longer meet users' needs for retrieval accuracy and speed. Vector retrieval technology has emerged as a solution. It encodes different types of data such as text, images, and audio into mathematical vectors and performs retrieval in vector space. This method allows systems to capture deep semantic information of data, thereby providing more accurate and efficient retrieval results.

This topic describes how to build your image search application using SeekDB's vector retrieval technology.

## Image search architecture

An image search application stores images in a database in vector form. Users upload images to be queried in the corresponding UI interface. The images are converted to vectors by the application, similar vectors are queried in the database, and results are returned. Finally, similar images are displayed on the UI page in image form.

## Prerequisites

* SeekDB is deployed.
  
* A database is created. For more information about creating a database, see [Create a database](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971662).

* Vector retrieval is enabled for the database. For more information about vector retrieval, see [Perform a vector search by using an SQL statement](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001976352).

    ```shell
    obclient> ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
    ```

* Prepare the images you need. If you do not have enough images to test the effect, you can refer to image datasets from major open-source websites.
* Python 3.9 or later is installed.

* Poetry is installed:

    ```shell
    python3 -m ensurepip
    python3 -m pip install poetry
    ```

## Procedure

1. Clone the code repository.

    ```shell
    git clone https://gitee.com/oceanbase-devhub/image-search.git
    cd image-search
    ```

2. Install dependencies.

    ```shell
    poetry install
    ```

3. Set environment variables.

    ```shell
    cp .env.example .env
    # Update database information in the .env file
    vi .env
    ```

    Update the content in `.env`.

    ```shell
    HF_ENDPOINT=https://hf-mirror.com

    DB_HOST="127.0.0.1"   ## Set the corresponding server IP
    DB_PORT="2881"   ## Set the corresponding port
    DB_USER="root" ## Set the corresponding tenant and username
    DB_NAME="test"   ## Set the corresponding database name
    DB_PASSWORD=""  ## Set the password for the tenant user
    ```

4. Upload the prepared images to the server.

5. Start the image search program.

    ```shell
    poetry run streamlit run --server.runOnSave false image_search_ui.py
    ```

    The following result is returned:

    ```shell
    Collecting usage statistics. To deactivate, set browser.gatherUsageStats to false.

        You can now view your Streamlit app in your browser.

        Local URL: http://localhost:8501
        Network URL: http://xxx.xxx.xxx.xxx:8501
        External URL: http://xxx.xxx.xxx.xxx:8501
    ```

6. Open the UI interface for image search. You can open the corresponding URL from Step 5 based on your actual situation.
7. Under **Image Loading Settings**, enter the absolute path of the directory where images are stored on the server in **Image Loading Directory**.
8. Click **Load Images**.
9. After images are loaded, you can perform image search operations.
