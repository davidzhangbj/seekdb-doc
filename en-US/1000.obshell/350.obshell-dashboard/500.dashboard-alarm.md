# Alert management

Log in to the obshell Dashboard console and click **Alert Center** in the left-side navigation pane to go to the **Alert Center** page.

The **Alert Center** page allows you to centrally manage and monitor alert events in a SeekDB instance. You can view and manage alert events, set alert suppression rules, and configure alert rules on this page. This helps you respond to and handle exceptions in a timely manner, ensuring system stability.

<main id="notice" type='explain'>
   <h4>Note</h4>
   <p>When you log in to the Alert Center page for the first time, you need to enter the Alertmanager address, username, and password. If you have not installed Alertmanager, we recommend that you install it by following the instructions in <a href="../900.configure-monitor.md">Configure monitoring components</a>.</p>
</main>

## Filter

You can filter the content in the **Events**, **Muted Events**, and **Rules** tabs based on the conditions. The supported conditions vary across tabs. You can configure the conditions and then perform precise searches. Click **Reset** to clear the query content and re-enter the query content.

| Parameter | Description |
| --- | --- |
| Alert Level | You can select an alert level from the drop-down list. The alert levels are **Critical**, **Major**, **Minor**, and **Notice**.<ul><li><b>Critical</b>: The system availability has declined and needs to be fixed immediately to avoid complete unavailability. </li><li><b>Major</b>: The system is still available, but it is about to reach an unavailable state. Measures must be taken to prevent the availability from declining. </li><li><b>Minor</b>: Key performance metrics of the system are declining, but they have not reached the level that triggers a major alert. Potential issues can be identified and resolved to avoid major alerts. </li><li><b>Notice</b>: This is an operational notice, not an alert. It is usually triggered by an administrator performing an important operation. </li></ul> |
| Keyword | The keyword for the alert. You can enter a custom keyword and search for the corresponding alert. |
| Start Time | The start time of the alert. |
| End Time | The end time of the alert. |

## Events

You can view the details of each alert in the **Events** tab, including **Event**, **Alert Level**, **Status**, **Start Time**, **End Time**, and the actions that you can perform on the event. You can sort the alerts by **Alert Level**, **Status**, **Start Time**, and **End Time**.

![Events](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/obshell/500.dashboard-alarm-01.png)

### Mute an alert

If you do not need to pay attention to an alert, you can click **Mute** in the **Actions** column of the alert to quickly mute the alert.

After you click **Mute**, the page switches to the **Muted Events** tab and the **Mute Conditions** drawer appears. The **Mute Conditions** drawer is automatically filled with the **Muted Alert Rule** and **Tags** information corresponding to the selected alert. You only need to select **Mute End Time** and enter **Remarks**. You can set the **Mute End Time** in the following two ways:

* Click the selection box and use the time selector to customize the end time.

* Click the selection box and set a fixed mute duration. For example, if you click **6 Hours**, the system will fill in the current time + 6 hours into the box.

After an alert is muted, the **Muted Events** tab will display a new mute record. In the **Events** tab, the status of the corresponding alert will change from **Active** to **Muted**. Muted alerts will not be sent before the set end time. If you need to send the alert earlier, you can modify the mute record in the **Muted Events** tab or **Unmute** the alert. For more information, see [Edit a mute record](#edit-mute-record) and [Unmute an alert](#unmute).

![Mute](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/obshell/500.dashboard-alarm-02.png)

## Alert suppression

In the suppression list, you can view the **Alert Rule**, **End Time**, **Creator**, **Status**, **Creation Time**, and **Remarks** of the suppression rules, as well as the operations that can be performed. You can sort the suppression rules based on **End Time**, **Status**, and **Creation Time**. You can also edit or remove specific suppression rules. When you hover the pointer over the **Alert Rule** column, the alert rule details are displayed.

![Alert suppression](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/obshell/500.dashboard-alarm-03.png)

### Create a suppression rule

On the **Alert Suppression** tab, click **Create Suppression Rule**. In the **Suppression Conditions** drawer, configure the suppression conditions and click **Submit**. The system returns to the **Alert Suppression** tab and adds the suppression rule to the suppression list.

| Parameter | Description |
| --- | --- |
| Alert Rule | In the drop-down list, select the alert rule that you want to suppress. You can select multiple alert rules. The alert rules in the **Alert Rule** list on the **Alert Rules** tab are consistent with those in this drop-down list. You can view the details of an alert rule on the **Alert Rules** tab. |
| Tag | Optional. You can specify the tag matching condition for alert suppression. You can specify a value or a regular expression. An alert is suppressed only when all the conditions are met. <main id="notice" type='explain'><h4>Note</h4><p>Generally, you do not need to configure this parameter. </p></main>  |
| End Time | The end time of alert suppression. Alerts are not sent before the end time. You can configure the end time in one of the following ways: <ul><li>Click the checkbox and use the time selector to specify the end time. </li><li>Click the checkbox and set the fixed suppression duration. For example, if you click <b>6 hours</b>, the system automatically fills the current time plus 6 hours into the field. </li></ul> |
| Remarks | You can add remarks to the suppression rule for easy identification and reuse. |

<main id="notice" type='explain'>
   <h4>Note</h4>
   <p>To suppress an alert, we recommend that you go to the <b>Alert Events</b> tab and suppress the alert event. After you click the <b>Suppress</b> field in the <b>Actions</b> column, the system automatically jumps to the <b>Alert Suppression</b> tab and displays the <b>Suppression Conditions</b> drawer. In the drawer, the system automatically fills the <b>Alert Rule</b> and <b>Tag</b> information associated with the alert event. You only need to configure the end time of alert suppression and add remarks. Then, the alert is suppressed. </p>
</main>

![Create an alert suppression rule](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/obshell/500.dashboard-alarm-04.png)

### Edit a suppression rule

On the **Alert Suppression** tab, in the **Suppression List** section, click **Edit** in the **Actions** column. In the **Suppression Conditions** drawer, you can edit the suppression rule.

The **Suppression Conditions** drawer automatically fills the **Alert Rule**, **Tag**, **End Time**, and **Remarks** information of the suppression rule. You can modify the parameters as needed. For more information, see [Create a suppression rule](#create-a-suppression-rule). After you click **Submit**, the suppression rule is edited.

After a suppression rule is edited, the suppression list is updated with the new suppression rule. The status of the original suppression rule is changed from **Active** to **Expired** and no further operations can be performed on it.

![Edit a suppression rule](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/obshell/500.dashboard-alarm-05.png)

### Remove a suppression rule

On the **Alert Suppression** tab, in the **Suppression List** section, click **Remove** in the **Actions** column. In the confirmation dialog box that appears, click **Remove**. The suppression rule is removed. After the suppression rule is removed, the status of the suppression rule is changed from **Active** to **Expired** and no further operations can be performed on it.

<main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>After a suppression rule is removed, it cannot be recovered. Proceed with caution. </p>
</main>

![Remove a suppression rule](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/obshell/500.dashboard-alarm-06.png)

## Alert rules

In the rule list, you can view the **Alert Rule Name**, **Trigger Rule**, **Duration**, **Object Type**, **Alert Level**, and **Type**. You can sort the rules by **Alert Level** and filter the rules by **Type** to view **Custom** or **Default** rules.

<main id="notice" type='explain'>
   <h4>Note</h4>
   <p>obshell Dashboard does not support custom alert rules. You can visit the <a href="https://github.com/oceanbase/obdeploy/blob/master/plugins/prometheus/2.37.1/prometheus_rules.yaml">GitHub repository</a> of obd to view the Prometheus alert rules provided by OceanBase. </p>
</main>
