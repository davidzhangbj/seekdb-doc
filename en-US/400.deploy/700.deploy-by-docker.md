# Deploy SeekDB in a container environment

This topic describes how to deploy SeekDB through Docker containers.

## Prerequisites

Before performing the operations in this topic, you need to confirm the following information:

* Docker is installed and the Docker service is started. For details, see [Docker documentation](https://docs.docker.com/get-docker/).
  
  <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>On x86 architecture MAC machines, only Docker V4.9.0 and earlier versions are supported for deploying SeekDB. You can click <a href="https://desktop.docker.com/mac/main/amd64/81317/Docker.dmg?_gl=17jelfd_gcl_auOTk5Nzk0MDUwLjE3MTE4ODMyNzM._gaNDQyMjE1MDE5LjE3MTE4ODMyNzQ._ga_XJWPQMJYHQ*MTcxOTIxOTEwMy4xMS4xLjE3MTkyMjEwMTAuNjAuMC4w">this link</a> to download Docker.</p>
  </main>

* Your machine meets the software and hardware requirements. For details, see [Server configuration requirements](300.preparations-before-deploy/100.prepare-servers.md).

## Deploy SeekDB

### (Optional) Step 1: Pull the SeekDB image

Run the following commands to pull the required SeekDB image.

* Search for SeekDB-related images

  ```shell
  [admin@test001 ~]$ sudo docker search seekdb
  ```

* Pull the latest SeekDB image

  ```shell
  [admin@test001 ~]$ sudo docker pull oceanbase/seekdb
  ```

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>
    <p>If pulling the Docker image fails, you can also pull the image from the quay.io or ghcr.io repository by replacing <code>oceanbase/seekdb</code> in the pull command with <code>quay.io/oceanbase/seekdb</code> or <code>ghcr.io/oceanbase/seekdb</code>, for example, run <code>sudo docker pull quay.io/oceanbase/seekdb</code> to pull the image from quay.io.</p>
    </li>
    <li>
    <p>After changing the repository address in the commands in this step, you need to synchronously replace the repository address in the commands in Step 2. The repositories used in both commands must be consistent.</p>
    </li>
    <li>
    <p>The above commands pull the latest version by default. You can select a version from <a href="https://hub.docker.com/r/oceanbase/oceanbase-ce/tags">dockerhub</a>, <a href="https://quay.io/repository/oceanbase/oceanbase-ce?tab=tags">quay.io</a>, or <a href="https://github.com/oceanbase/docker-images/pkgs/container/oceanbase-ce">ghcr.io</a> according to your actual needs.</p>
    </li>
    </ul>
  </main>

### Step 2: Start the SeekDB instance

Run the following command to start the SeekDB instance.

```shell
[admin@test001 ~]$ sudo docker run -d --restart unless-stopped -p 2881:2881 --name obseekdb -v /home/admin/seekdb:/var/lib/oceanbase  oceanbase/seekdb
```

The options in the example work as follows:

* `-p` is used to map container ports to host ports. In the example, port `2881` in the container is mapped to port `2881` on the host.

* `-v` is used to share files or directories between the container and the host to achieve data persistence or configuration sharing. Here, `/home/admin/seekdb` is the host directory, and `/var/lib/oceanbase` is the directory in the container. Do not modify the directory in the container.

* `--name` is used to set the Docker container name. For example, a Docker container named `obseekdb` is created in the example.

### Step 3: Connect to the SeekDB instance

You can use the OBClient or MySQL client on the host to connect to the SeekDB instance.

```shell
[admin@test001 ~]$ mysql -uroot -h127.0.0.1 -P2881 -p
```

<main id="notice" type='explain'>
  <h4>Note</h4>
  <p>If the password is not configured through environment variables when starting the SeekDB instance, users created in the instance use empty passwords by default.</p>
</main>
