# What is SeekDB

OceanBase SeekDB (referred to as SeekDB) is a next-generation, developer-friendly database product from OceanBase, focused on delivering efficient hybrid search capabilities for AI applications. It provides unified storage and retrieval for vector, full-text, and multimodal data. SeekDB inherits the high-performance advantages of the core engine and full MySQL compatibility of OceanBase, and optimizes its data search architecture to better meet the needs of AI data processing.

## Product architecture

![seekdb-arch](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/seekdb-arch.jpg)

* **Deployment mode**: Supports embedded and server deployment modes. In embedded mode, SeekDB can be directly integrated into Python applications, making it ideal for personal development.

* **Multi-modal data and indexing layer**: Supports vector, text, JSON, and GIS data types, with efficient indexing capabilities. Includes HNSW/IVF vector indexing and quantization algorithms, BM25-based full-text indexing with multiple tokenizers and query modes, hybrid indexing for multimodal search, JSON indexing for metadata search, and primary/secondary key, GIS, and other indexing capabilities.

* **Multi-modal compute layer for hybrid workloads**: Supports hybrid search across vectors, full-text, and scalar data, enhancing query accuracy in RAG scenarios. Provides AI Function capabilities for real-time inference within the database. Supports complete ACID transaction features and multi-version concurrency control (MVCC), along with a query optimizer, adaptive execution engine, and flexible PL UDF functionality, to better meet diverse business needs.

* **Unified application interface**: Compatible with native MySQL drivers, and offers a unified query language for multi-modal data. Provides user-friendly vector and hybrid search SDKs. Compatible with nearly 30 application development frameworks, including AI-focused ones like LangChain, LlamaIndex, and Dify. Offers an MCP server for seamless integration with the AI ecosystem.

## Applicable scenarios

### RAG applications

For scenarios such as intelligent chatbots, knowledge bases, and domain expert systems, SeekDB provides a complete RAG pipeline solution. This solution integrates document parsing, vector embedding (Embedding), result reranking (Rerank), and large language model (LLM) interaction capabilities, supporting hybrid search across vectors, full-text, and scalars. It enables end-to-end processing (Doc In Data Out) within a single database instance. For example, in a knowledge base scenario, SeekDB can efficiently retrieve factual information from the knowledge base to provide accurate and real-time data support for the LLM, enhancing the accuracy of generated content and enabling explainable generation.

### AI-assisted programming

For AI-assisted programming scenarios, SeekDB supports building vector and full-text indexes for code repositories. It enables efficient code search and generation completion based on code keywords or semantics. Additionally, SeekDB offers robust data organization capabilities, supporting structured storage (such as syntax trees and dependency relationship graphs) and unstructured storage (such as raw code text) of code snippets. It also provides dynamic metadata management for flexible extension and efficient querying of code properties (such as language type, function names, and parameter lists).

### AI Agent platforms

SeekDB provides a one-stop data solution for AI Agent development, supporting rapid startup and embedded deployment to meet agile development needs. Its high-performance engine ensures high-frequency CRUD operations and real-time query capabilities, effectively eliminating performance bottlenecks that can hamper AI development. With built-in vector search, full-text search, and hybrid search capabilities, along with flexible metadata management and session management, and integrated memory storage modules, SeekDB allows for the rapid construction of complete AI Agents without the need for additional libraries, significantly reducing system complexity and development barriers.

### Semantic search engines

For scenarios such as e-commerce product search and recommendation, multimedia content retrieval, image search, and facial recognition, SeekDB provides a comprehensive vector search solution. It supports integration with mainstream vector embedding models, storing text or image features as vectors in SeekDB and enabling efficient similarity calculations through high-performance indexing to quickly return the most relevant results. Additionally, SeekDB's Semantic Index feature simplifies the development process by automatically embedding text queries and reranking results, eliminating the need to manage complex underlying implementations. This significantly lowers the integration threshold between AI applications and the database, making semantic search more user-friendly and efficient.

### MySQL application modernization and AI upgrade

SeekDB inherits the full capabilities of OceanBase Database's standalone storage engine, execution engine, transaction engine, and advanced query optimizer, and is highly compatible with MySQL. It extends AI capabilities beyond MySQL compatibility. Small-scale deployments are ideal for scenarios like IoT edge data collection, small-scale application development, and educational experiments. For medium and large-scale deployments, SeekDB can support OLTP and HTAP workloads across a wide range of industries.

## Core features

### Easy to use, fast development, and intuitive

Designed with a single-node architecture, SeekDB allows for quick installation and configuration. It runs out of the box with no additional components, making it ideal for agile AI development. It supports flexible deployment options, including server and embedded modes. In server mode, it can be deployed using yum install, Docker, or Windows/macOS desktop versions. In embedded mode, it integrates natively with Python, allowing it to be embedded directly into AI applications. It is compatible with nearly 30 application development frameworks, including AI-focused ones like LangChain, LlamaIndex, and Dify. It can be quickly set up for AI application development in just a few minutes.

### Minimum specification: 1C2G, vertical elastic scalability

SeekDB can run with as little as 1 CPU core and 2 GB of memory for benchmark testing. For higher concurrency, more data, or more complex queries, you can easily scale up resources vertically to meet your requirements.

### High-performance vector and full-text indexing, hybrid search

* Vector search: Supports storage and fast retrieval of vectors up to 16,000 dimensions, and works with multiple distance metrics like L2, inner product, and cosine similarity. It offers HNSW and IVF indexing, as well as quantization algorithms for approximate nearest neighbor search, meeting the semantic retrieval needs of AI applications.

* Full-text search: Delivers high-performance full-text indexing with BM25 relevance ranking for precise keyword searches. It supports multiple tokenizers (Space, Beng, Ngram, IK, and Jieba) and query modes (Natural Language, Boolean, Phrase, and Multi Match), enabling fast and efficient searches across massive text datasets.

* Hybrid search: Supports hybrid queries across vectors, full-text, scalars, and spatial data in a single SQL statement.

### Vector search upgrade, semantic search with text input

SeekDB provides a Semantic Index feature that automatically embeds text data and generates vector indexes. You can perform semantic searches by specifying text query conditions. It abstracts away the complexity of vector embedding and query result reranking, simplifying the use of SeekDB for AI application development.

### Seamless model integration, built-in AI functions for real-time in-database inference

SeekDB can connect to large language models and vector embedding models, managed through the `DBMS_AI_SERVICE` system package. Built-in AI functions like `AI_COMPLETE`, `AI_PROMPT`, `AI_EMBED`, and `AI_RERANK` enable real-time AI data processing and inference within the database using SQL expressions.

### Dynamic JSON-based schema for efficient document metadata storage and access

SeekDB supports the JSON data type with dynamic schema capabilities. Partial updates to JSON reduce update costs, while JSON function and multi-valued indexes optimize query performance. Semi-structured encoding lowers storage expenses. In AI applications, JSON can store document metadata and participate in hybrid searches with full-text and vector data.

### Real-time data ingestion and immediate query availability

With its LSM-Tree storage architecture, SeekDB enables high-frequency, real-time data writes. Whenever you perform DML operations, full-text, vector, and scalar indexes are built synchronously, so your data is instantly available for querying as soon as it is inserted.

### Beyond MySQL compatibility: HTAP hybrid workloads

SeekDB is fully compatible with MySQL syntax, protocols, and data dictionaries, ensuring seamless migration of MySQL applications. It breaks the limitations of MySQL's supported scenarios through innovative architecture. Based on row-and-column storage and vectorized execution, a single SeekDB instance can handle both transactional (OLTP) and real-time analytical (HTAP) workloads, eliminating the need for data synchronization delays and maintaining sync pipelines.
