# What is SeekDB

OceanBase SeekDB (referred to as SeekDB) is a next-generation, developer-friendly database product from OceanBase, focused on delivering efficient hybrid search capabilities for AI applications. It provides unified storage and retrieval for vector, full-text, and multimodal data. As a key member of the OceanBase product family, SeekDB inherits the high-performance advantages of the core engine and full MySQL compatibility, while deeply optimizing its data search architecture to better meet the needs of AI data processing.

## Product architecture

![seekdb-arch](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/seekdb-arch.jpg)

* **Storage layer**: Features a unified row-and-column storage engine built on LSM-Tree architecture, with self-developed advanced encoding and compression techniques to reduce storage costs. Supports high-frequency, real-time data writes and high-performance queries for various workloads. Enables efficient storage for basic, multimodal, and vector data types, with robust indexing support.

* **Compute layer**: Supports hybrid search across vectors, full-text, and scalar data, with an advanced query optimizer and a high-performance execution engine capable of vectorized operations. Delivers full ACID (atomicity, consistency, isolation, and durability) transaction support and multi-version concurrency control (MVCC) for stable handling of diverse business requests.

* **Interface layer**: Compatible with native MySQL drivers, and offers user-friendly vector and hybrid search SDKs such as pyobvector and obvec_jdbc.

* **Application framework layer**: Compatible with nearly 30 application development frameworks, including AI-focused ones like LangChain, LlamaIndex, and Dify. Provides an MCP server for seamless connection to the AI ecosystem. Supports both Client/Server and embedded deployment modes.


## Core features

### Simple deployment, instant initialization

SeekDB uses a single-node architecture, so you do not need complex configurations. Initialization takes just seconds. You can choose either client/server or embedded deployment. For client/server mode, installation options include yum, Docker, or Windows/macOS desktop versions. For embedded mode, SeekDB integrates natively with Python, allowing it to be embedded directly into AI applications.

### Minimum specifiation: 1C1G, vertical elastic scalability

SeekDB can run with as little as 1 CPU core and 1 GB of memory for trial use, though 4 GB of memory is recommended for vector and hybrid search scenarios. If you need higher concurrency, more data, or more complex queries, you can easily scale up resources vertically to meet your requirements.

### High-performance vector and full-text indexing, hybrid search

* Vector search

    SeekDB supports storage and fast retrieval of vectors up to 16,000 dimensions, and works with multiple distance metrics like L2, inner product, and cosine similarity. It offers HNSW and IVF indexing, as well as quantization algorithms for approximate nearest neighbor search, meeting the semantic retrieval needs of AI applications.

* Full-text search

    SeekDB delivers high-performance full-text indexing with BM25 relevance ranking for precise keyword searches. It supports multiple tokenizers (Space, Beng, Ngram, IK, and Jieba) and query modes (Natural Language, Boolean, Phrase, and Multi Match), enabling fast and efficient searches across massive text datasets.

* Hybrid search

    SeekDB supports hybrid queries across vectors, full-text, scalars, and spatial data in a single SQL statement.

SeekDB's hybrid index feature automatically embeds text data and generates vector indexes, allowing semantic search simply by specifying text query conditions. This supports multimodal queries for Retrieval-Augmented Generation (RAG) solutions, helping enterprises build intelligent, efficient data retrieval systems.

SeekDB supports SQL, Python SDK, and Java SDK interfaces, making it easy to integrate with different application environments.

### Seamless model integration, built-in AI functions for real-time in-database inference

SeekDB can connect to chat and embedding models, managed through the DBMS_AI_SERVICE system package. Built-in AI functions like AI_COMPLETE, AI_EMBED, and AI_RERANK enable real-time AI data processing and inference within the database using SQL expressions.

### Dynamic JSON-based schema for efficient document metadata storage and access

SeekDB supports the JSON data type with dynamic schema capabilities. Partial updates to JSON reduce update costs, while JSON function and multi-valued indexes optimize query performance. Semi-structured encoding lowers storage expenses. In AI applications, JSON can store document metadata and participate in hybrid searches with full-text and vector data.

### Real-time data ingestion and immediate query availability

With its LSM-Tree storage architecture, SeekDB enables high-frequency, real-time data writes. Whenever you perform DML operations, full-text, vector, and scalar indexes are built synchronously, so your data is instantly available for querying as soon as it is inserted.

### Beyond MySQL compatibility: HTAP hybrid workloads

SeekDB is fully compatible with MySQL syntax, protocols, and views, but goes further by supporting a wider range of compute and storage engines. Thanks to row-and-column storage and vectorized execution, a single SeekDB instance can handle both transactional (OLTP) and real-time analytical (HTAP) workloads, so you do not have to worry about data synchronization delays or maintaining sync pipelines.

## FAQs

* Q: What is the difference between SeekDB and OceanBase Database Standalone Edition?

	A: OceanBase Database Standalone Edition is designed for enterprise users and offers all the features of the distributed version in a single-node product. It is suitable for non-core or small-to-medium-sized workloads, and can be smoothly upgraded to the distributed version. SeekDB, on the other hand, is a new, ecosystem-oriented database with a lower entry barrier. It removes complex features like multi-tenancy, distributed processing, and Oracle compatibility, and focuses on quickly iterating DB4AI capabilities in a MySQL-compatible form.

* Q: Can I upgrade directly from SeekDB to OceanBase Database?

	A: Direct upgrade is not supported, but logical migration from SeekDB to OceanBase Database is possible.
  
* Q: What is the evolution strategy for SeekDB and OceanBase Database?

	A: SeekDB is built on OceanBase Database V4.3.5 and includes most of its features. Currently, both products are evolving independently. AI-related features will be developed and updated more quickly in SeekDB, but they will eventually be supported in OceanBase Database as well.
