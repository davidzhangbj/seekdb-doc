# What is SeekDB

OceanBase SeekDB (referred to as SeekDB) is a next-generation, developer-friendly database product from OceanBase, focused on delivering efficient hybrid search capabilities for AI applications. It provides unified storage and retrieval for vector, full-text, and multi-model data. SeekDB inherits the high-performance advantages of OceanBase's core engine and full MySQL compatibility, while deeply optimizing its data search architecture to provide developers with solutions that better meet the needs of AI application data processing.

## Product architecture

![seekdb-arch](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/seekdb-arch.jpg)

* **Deployment modes**: Supports both embedded and server deployment modes. In embedded mode, SeekDB can be directly integrated into Python applications, facilitating personal development.

* **Multi-model data and indexing layer**: Supports multi-model data types, including vectors, text, JSON, and GIS, with efficient indexing support. Includes HNSW/IVF vector indexes and quantization algorithms, full-text indexes based on BM25 relevance calculation covering multiple tokenizers and query modes, hybrid indexes for hybrid search, JSON indexes for metadata search, as well as primary keys, secondary indexes, GIS indexes, and more.

* **Multi-model compute layer supporting hybrid workloads**: Supports hybrid search across vectors, full-text, and scalar conditions, improving query result accuracy in RAG scenarios. Provides AI Function capabilities to support real-time inference within the database. Supports complete ACID transaction features and multi-version concurrency control (MVCC) capabilities, with query optimizers suitable for hybrid workloads, adaptive execution engines, and flexible PL UDF functions to better meet diverse business needs.

* **Unified application interface**: Compatible with native MySQL drivers, providing a unified query language based on SQL that supports multi-model data. Additionally, implements developer-friendly vector library/hybrid search SDKs. Compatible with nearly 30 application development frameworks, including AI-focused ones like LangChain, LlamaIndex, and Dify. Provides an MCP server for seamless integration with the AI ecosystem.

## Applicable scenarios

### RAG applications

For Retrieval-Augmented Generation (RAG) scenarios such as intelligent chatbots, knowledge bases, and domain expert systems, SeekDB provides a complete RAG Pipeline solution. This solution integrates document parsing, vector embedding, result reranking, and large language model (LLM) interaction capabilities, supporting hybrid search across vectors, full-text, and scalar data, enabling end-to-end processing from document input to data output (Doc In Data Out) within a single database instance. Taking knowledge base scenarios as an example, SeekDB can efficiently retrieve factual information from knowledge bases, providing accurate and real-time data support for LLMs, enhancing both the accuracy of generated content and the explainability of the generation process.

### AI-assisted programming

For AI-assisted programming scenarios, SeekDB supports building vector and full-text indexes on code repositories, enabling efficient code search and generation completion based on code keywords or code semantics. Additionally, SeekDB provides efficient data organization capabilities, supporting structured storage of code snippets (such as syntax trees and dependency relationship graphs) and unstructured storage (such as raw code text), and implements flexible extension and efficient querying of code attributes (such as language type, function names, parameter lists) through dynamic metadata management.

### AI Agent platform applications

SeekDB provides a one-stop data solution for AI Agent development, supporting rapid startup and embedded deployment to quickly launch services to meet agile development needs. Its high-performance engine ensures high-frequency CRUD operations and real-time query capabilities, effectively eliminating the impact of database performance bottlenecks on AI development efficiency. Built-in vector search, full-text search, and hybrid search capabilities, combined with flexible metadata management and session management capabilities, as well as integrated memory storage modules, enable rapid construction of complete AI Agents without introducing additional libraries, reducing system complexity and development barriers.

### Semantic search engines

For semantic search scenarios such as e-commerce product search and recommendation, multimedia content retrieval, image search, and face recognition, SeekDB provides a complete vector search solution. Supports integration with mainstream vector embedding models, storing text or image features as vectors in SeekDB, and achieving efficient similarity calculations through high-performance indexes to quickly return the most matching results for query content. Additionally, SeekDB's Semantic Index feature further simplifies the development process. Users only need to submit text queries to automatically complete vector embedding and result reranking (Rerank), without needing to focus on underlying complex implementations, significantly reducing the integration barrier between AI applications and databases, making semantic search more user-friendly and efficient.

### MySQL application modernization and AI upgrade

SeekDB inherits the complete capabilities of OceanBase Database's standalone storage engine, execution engine, transaction engine, and advanced query optimizer, and is highly compatible with MySQL, while extending AI capabilities on this basis. Smaller deployments are ideal for scenarios such as IoT edge device data collection, small-scale application development, and educational experiments. Medium and large-scale deployments can support OLTP, HTAP, or AI business scenarios across various industries.

## Core features

### Out-of-the-box, rapid development, easy to learn and use

Single-node architecture design enables quick installation and configuration. No other component dependencies, single-node startup for immediate operation, suitable for agile AI business development scenarios. Provides flexible and diverse deployment options, supporting both server and embedded deployment modes: in server deployment mode, supports yum install, docker, or Windows/macOS desktop versions; in embedded deployment mode, native Python integration, can be used as an embedded database in AI applications. Already integrated with various AI application development frameworks, enabling rapid AI application construction in minutes.

### Support for 1C2G small specifications, vertical elastic scaling

1 CPU core + 2 GB memory can run VectorDBBench Performance1536D50K benchmark tests. When higher requirements for system concurrency, data volume, or query complexity are needed, resources can be flexibly scaled vertically.

### High-performance vector and full-text indexing, supporting hybrid search across vectors, full-text, and scalars

* Vector search: Supports storage and high-performance retrieval of vectors up to 16,000 dimensions, compatible with multiple distance calculation methods such as L2, inner product, and cosine similarity. Provides HNSW/IVF indexes and related quantization algorithms, supporting both exact nearest neighbor and approximate nearest neighbor search, meeting diverse vector retrieval needs in AI scenarios.

* Full-text search: Supports high-performance full-text indexing based on BM25 relevance ranking algorithms to achieve precise keyword-based searches. Provides multiple tokenizers such as Space, Beng, Ngram, IK, and Jieba, supports multiple query modes including Natural Language Mode, Boolean Mode, Phrase Query, and Multi Match, enabling efficient retrieval of relevant text that meets filtering rules from massive data.

* Hybrid search: Supports hybrid search across multiple data types including vectors, full-text, scalars, and spatial data, completing multi-path queries and reranking in a single SQL statement, greatly improving query result accuracy in RAG applications.

### Vector search upgrade: semantic search based on Semantic Index with text specification

SeekDB provides Semantic Index functionality. Users only need to write text data, and the system automatically performs Embedding and generates vector indexes. When querying, users only need to specify text search conditions to perform semantic search. This shields users from the complex processes of vector embedding and query result Rerank, simplifying the database usage for AI application development.

### Seamless model integration, built-in AI functions for real-time in-database inference

SeekDB supports integration with large language models and vector embedding models, implementing model registration and management through the `DBMS_AI_SERVICE` system package. Built-in AI Functions such as `AI_COMPLETE`, `AI_PROMPT`, `AI_EMBED`, and `AI_RERANK` support data embedding and real-time in-database inference under standard SQL syntax.

### Dynamic JSON-based schema for efficient document metadata storage and access

SeekDB supports the JSON data type with dynamic schema capabilities. Supports partial updates to JSON to reduce data update costs, provides JSON function indexes and multi-value indexes to optimize query performance. Implements semi-structured encoding to reduce storage costs. In AI applications, JSON can be used as a storage type for document metadata and supports hybrid search capabilities with full-text and vector data.

### Real-time data ingestion, immediately queryable

Based on LSM-Tree storage architecture, SeekDB supports high-frequency real-time data writes. When performing DML operations, full-text, vector, scalar, and other indexes are built synchronously, making data immediately queryable upon successful insertion.

### Beyond MySQL compatibility: supporting HTAP workloads

Deeply compatible with MySQL syntax, protocols, data dictionaries, etc., ensuring seamless migration of MySQL applications. At the same time, through innovative architecture, breaks through the scenario boundaries supported by MySQL. Based on hybrid row-and-column storage technology and vectorized execution capabilities, a single instance can simultaneously support multiple workloads such as online transactions and real-time analysis, eliminating data synchronization delays and maintenance costs of synchronization pipelines.
