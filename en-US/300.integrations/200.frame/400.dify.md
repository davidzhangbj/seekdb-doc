# Integrate SeekDB Vector with Dify

SeekDB supports vector type storage, vector indexing, and vector retrieval. You can store the vectorized data in SeekDB for subsequent retrieval.

Dify is an open-source large language model (LLM) application development platform. It combines the concepts of Backend as a Service (BaaS) and LLMOps, enabling developers to quickly build production-grade generative AI applications. Even non-technical users can participate in defining AI applications and managing data operations.

Dify is equipped with the essential technology stack for building LLM applications, including support for hundreds of models, an intuitive prompt orchestration interface, high-quality RAG engine, robust agent framework, flexible process orchestration, and a user-friendly interface and API. This saves developers from repeatedly reinventing the wheel, allowing them to focus on innovation and business requirements.

This topic describes how to integrate the vector retrieval feature of SeekDB with Dify.

## Prerequisites

* Before you deploy Dify, make sure that your server meets the following minimum system requirements:

  * CPU: 2 cores
  * Memory: 4 GB

* This integration tutorial is performed in a Docker container platform. Make sure that you have set up the [Docker container platform](https://docs.docker.com/get-started/get-docker/).

* You have deployed SeekDB.

## Step 1: Obtain database connection information

Contact the SeekDB deployment personnel or administrator to obtain the database connection string, for example:

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: specifies the IP address for connecting to SeekDB.
* `$port`: specifies the port for connecting to SeekDB. The default value is `2881`.
* `$database_name`: specifies the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user for the connection must have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> permissions on the database. </p>
    </main>

* `$user_name`: specifies the database connection account.
* `$password`: specifies the account password.

## Step 2: Deploy Dify

### Method 1

For more information about how to deploy Dify, see [Deploy Dify by using Docker Compose](https://docs.dify.ai/zh-hans/getting-started/install-self-hosted/docker-compose).

Make the following modifications:

* Change the value of the `VECTOR_STORE` variable in the `.env` file to `oceanbase`.
* Run the `docker compose --profile oceanbase up -d` command to start the service.

### Method 2

You can also refer to [Dify for MySQL](https://github.com/oceanbase/dify-on-mysql) to quickly start the Dify service.

The steps are as follows:

```shell
cd docker
bash setup-mysql-env.sh
docker compose up -d
```
