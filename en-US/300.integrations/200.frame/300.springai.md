# Integrate Spring AI Alibaba with seekdb Vector

seekdb supports vector type storage, vector indexing, and embedding vector retrieval. You can store the vectorized data in seekdb for use in subsequent retrieval steps.

The Spring AI Alibaba open-source project is built on Spring AI and serves as best practices for developing Java AI applications using Alibaba Cloud's Tongyi series models and services. It simplifies the AI application development process and adapts to cloud-native infrastructure, enabling developers to quickly build AI applications.

This topic demonstrates how to integrate Spring AI Alibaba with seekdb's vector retrieval capabilities to implement data import and similarity search. By configuring vector storage and retrieval services, developers can easily build AI application scenarios based on seekdb, supporting advanced features such as text similarity search and content recommendation.

## Prerequisites

* You have deployed seekdb.

* Download [JDK 17+](https://www.oracle.com/java/technologies/downloads/#java17). Make sure that you have installed Java 17 and configured the environment variables.

* Download [Maven](https://dlcdn.apache.org/maven/). Make sure that you have installed Maven 3.6+ to build the project and manage dependencies.

* Download [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) or [Eclipse](https://www.eclipse.org/downloads/). Choose the appropriate version based on your operating system and install it.

## Step 1: Obtain the database connection information

Contact the deployment personnel or administrator of seekdb to obtain the corresponding database connection string. For example:

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: the IP address for connecting to seekdb.
* `$port`: the port for connecting to seekdb. The default value is `2881`.
* `$database_name`: the name of the database to be accessed.

    <main id="notice" type='notice'>

    </main>

* `$user_name`: the database connection account.
* `$password`: the password of the account.

## Step 2: Create a Maven project

Maven is the project management and build tool used in this topic. In this step, you create a Maven project and add project dependencies by configuring the `pom.xml` file.

### Create a project

1. Run the Maven command to create a project.

    ```shell
    mvn archetype:generate -DgroupId=com.alibaba.cloud.ai.example -DartifactId=vector-oceanbase-example -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false
    ```

2. Go to the project directory.

    ```shell
    cd vector-oceanbase-example
    ```

The `pom.xml` file is the core configuration file of a Maven project. It is used to manage the project's dependencies, plugins, and build configurations. In this step, you need to modify the `pom.xml` file to add dependencies such as Spring AI Alibaba, seekdb vector storage, and others.

## Step 3: Configure the seekdb connection information

In this step, you configure the `application.yml` file to add the seekdb connection information.

Create the `application.yml` file in the `src/main/resources` directory of the project and add the following content:

```yaml
server:
  port: 8080

spring:
  application:
    name: oceanbase-example
  ai:
    dashscope:
      api-key: ${DASHSCOPE_API_KEY}  # Replace this value with your DashScope API key.
    vectorstore:
      oceanbase:
        enabled: true
        url: jdbc:oceanbase://xxx:xxx/xxx  # The seekdb connection URL.
        username: xxx                     # The seekdb username.
        password: xxx                     # The seekdb password.
        tableName: vector_table           # The name of the vector table (automatically created).
        defaultTopK: 2                    # The default number of similar results to return.
        defaultSimilarityThreshold: 0.8   # The similarity threshold (0~1, the smaller the value, the more similar the results).
```

## Step 4: Create the main application class and controller

Create the start class and controller class of the Spring Boot application to implement the data import and similarity search features.

### Create the application start class

In the `src/main/java/com/alibaba/cloud/ai/example/vector` directory of the project, create the `OceanBaseApplication.java` file and add the following content:

```java
package com.alibaba.cloud.ai.example.vector;  // The package name must be consistent with the directory structure.

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication  // Enable Spring Boot auto-configuration
public class OceanBaseApplication {
    public static void main(String[] args) {
        SpringApplication.run(OceanBaseApplication.class, args);  // Start the Spring Boot application
    }
}
```

The sample code is the core start class of the project, used to start the Spring Boot application.

### Create the vector store controller

In the `src/main/java/com/alibaba/cloud/ai/example/vector` directory of the project, create the `OceanBaseController.java` file and add the following content:

```java
package com.alibaba.cloud.ai.example.vector.controller;  // The package name must be consistent with the directory structure.

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

import com.alibaba.cloud.ai.vectorstore.oceanbase.OceanBaseVectorStore;

@RestController  // Mark as a REST controller
@RequestMapping("/oceanbase")  // Set the base path to /oceanbase
public class OceanBaseController {

    private static final Logger logger = LoggerFactory.getLogger(OceanBaseController.class);  // Logger

    @Autowired  // Automatically inject the OceanBase vector store service
    private OceanBaseVectorStore oceanBaseVectorStore;

    // Data import interface
    @GetMapping("/import")
    public void importData() {
        logger.info("Start importing data");

        // Create sample data
        HashMap<String, Object> map = new HashMap<>();
        map.put("id", "12345");
        map.put("year", "2025");
        map.put("name", "yingzi");

        // Create a list containing three documents
        List<Document> documents = List.of(
            new Document("The World is Big and Salvation Lurks Around the Corner"),
            new Document("You walk forward facing the past and you turn back toward the future.", Map.of("year", 2024)),
            new Document("Spring AI rocks!! Spring AI rocks!! Spring AI rocks!! Spring AI rocks!! Spring AI rocks!!", map)
        );

        // Add the documents to the vector store
        oceanBaseVectorStore.add(documents);
    }

    // Similarity search interface
    @GetMapping("/search")
    public List<Document> search() {
        logger.info("Start searching data");

        // Perform a similarity search for documents containing "Spring" and return the top 2 most similar results
        return oceanBaseVectorStore.similaritySearch(SearchRequest.builder()
                                                     .query("Spring")
                                                     .topK(2)
                                                     .build());
    }
}
```

## FAQ

### SeekDB connection failure

* Cause: The URL, username, or password is incorrect.
* Solution: Check the seekdb configuration in `application.yml` and ensure that the database service is started.

### Dependency conflict

* Cause: Multiple Spring Boot versions are conflicting.
* Solution: Use `mvn dependency:tree` to view the dependency tree and exclude the conflicting version.

### SNAPSHOT dependency cannot be downloaded

* Cause: The SNAPSHOT repository is not configured.
* Solution: Ensure that the `sonatype-snapshots` repository is added in `pom.xml`.
