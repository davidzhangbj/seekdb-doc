# Integrate seekdb with n8n

n8n is a workflow automation platform with native AI capabilities, offering the flexibility of code and the speed of no-code to technical teams. With over 400 integrations, native AI features, and a fair code license, n8n allows you to build powerful automation while maintaining complete control over your data and deployments.

This topic shows you how to build a Chat to seekdb workflow template using n8n's powerful features.

## Prerequisites

* You have deployed seekdb.

* This integration tutorial is conducted on a Docker container platform. Make sure you have set up the [Docker container platform](https://docs.docker.com/get-started/get-docker/).

## Step 1: Obtain the database connection information

Contact the seekdb deployment team or administrator to obtain the corresponding database connection string, for example:

```sql
obclient -h$host -P$port -u$user_name -p$password -D$database_name
```

**Parameter description:**

* `$host`: provides the IP address for connecting to seekdb.
* `$port`: provides the port for connecting to seekdb, default is `2881`.
* `$database_name`: the name of the database to be accessed.

    <main id="notice" type='notice'>
        <h4>Notice</h4>
        <p>The user needs to have the <code>CREATE</code>, <code>INSERT</code>, <code>DROP</code>, and <code>SELECT</code> permissions on the database.</p>
    </main>

* `$user_name`: provides the database connection account.
* `$password`: provides the account password.

## Step 3: Deploy the tool

### Deploy n8n privately

n8n is a workflow automation platform based on Node.js, providing rich integration capabilities and flexible scalability. By deploying n8n privately, you can better control the workflow environment and ensure data security and privacy. This section introduces how to deploy n8n in a Docker environment.

```shell
sudo docker run -d   --name n8n   -p 5678:5678   -e N8N_SECURE_COOKIE=false   n8nio/n8n
```

### Deploy the Qwen3 model using Ollama

Ollama is an open-source AI model server that supports the deployment and management of various AI models. By using Ollama, you can easily deploy the Qwen3 model locally to enable AI Agent functionality. This section introduces how to deploy Ollama in a Docker environment and then use Ollama to deploy the Qwen3 model.

```shell
# Deploy Ollama in a Docker environment
sudo docker run -d  -p 11434:11434 --name ollama ollama/ollama
# Deploy the Qwen3 model
sudo docker exec -it ollama sh -c 'ollama run qwen3:latest'
```

## Step 4: Build the AI Agent workflow

n8n provides a wide range of nodes, making it easy to build AI Agent workflows. This section shows you how to build a Chat to seekdb workflow template using n8n. You need to add 5 nodes, as follows:

1. Add a trigger

    Add an HTTP trigger node to receive HTTP requests.

    ![4-1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-1.png)

2. Add an AI Agent node

    Add an AI Agent node to handle AI Agent requests.

    ![4-2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-2.png)

3. Add an Ollama Chat Model node

    There are several free model options available. In this example, Qwen3 is used. After selecting the model, configure the Ollama account.

    ![4-3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-4.png)

    ![4-4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-3.jpg)

4. Add a Simple Memory node

    The Simple Memory node represents short-term memory and will remember the previous 5 interactions during the chat.

    ![4-5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-5.png)

5. Add a Tool node

    The Tool node is used to execute database operations in seekdb. Add the MySQL Tool under the AI agent-tool.

    ![4-6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-6.png)

    The MySQL Tool configuration is as follows:

    ![4-7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-8-1.png)

    Click the `Edit` icon shown in the figure above to configure the MySQL connection information.

    ![4-8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-7-1.png)

    After the configuration is complete, you can click `Test step` in the upper right corner of the configuration panel to test the database connection with a simple SQL statement, or directly click `Back to canvas` to return to the main interface.

6. Click Save to complete the workflow construction.

    After all 5 nodes are configured, click Save to complete the workflow construction and start testing.

    ![4-9](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/integrations/AI/n8n-9.png)
