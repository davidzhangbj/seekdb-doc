# seekdb Agent Skill

In the era of AI-assisted programming, developers increasingly rely on intelligent tools to improve coding efficiency. However, when using specific technology stacks (such as seekdb vector database), AI assistants often lack domain knowledge and cannot provide accurate code suggestions and assistance. To solve this problem, OceanBase provides the seekdb Agent Skill plugin, which is a skill plugin designed for Claude Code, allowing Claude Code to access the official seekdb documentation to obtain precise technical guidance during development.

The seekdb Agent Skill plugin provides the following features:

* Comprehensive documentation support: Retrieve knowledge from the official seekdb documentation, covering comprehensive technical documentation.
* Intelligent document search: Supports content-based search, allowing quick location of relevant documents.
* Remote-first strategy: Prioritize fetching the latest documentation from GitHub, with local documentation as a backup.
* Out-of-the-box usability: Simple configuration is required for use.

## Background information

### What is Claude Code

Claude Code is an AI programming assistant developed by Anthropic, designed to run directly in your development environment. It helps you understand codebases, write code, fix bugs, and perform various development tasks.

Unlike traditional IDE plugins, Claude Code is a standalone command-line tool with the following characteristics:

* Native terminal: Runs in the terminal, seamlessly integrating with your development workflow.
* Codebase-aware: Capable of understanding and analyzing the entire codebase structure.
* Natural language interaction: Describe your needs in natural language, and Claude Code will help you complete them.
* Multi-tool collaboration: Can read and write files, execute commands, and search code.

### What is Agent Skills

[Agent Skills](https://code.claude.com/docs/en/skills) are open standards introduced by Anthropic to grant new capabilities and expertise to AI agents. In simple terms, they are folders containing instructions, scripts, and resources that AI agents can discover and use to more accurately complete tasks.

## Installation and configuration

### Prerequisites

Before you begin, ensure that the following conditions are met:

* Node.js environment: Node.js 18 or later is required.

* Network access: Ability to access GitHub (for installing the plugin and retrieving the latest documentation).

### Step 1: Install Claude Code

If you haven't installed Claude Code yet, you can install it globally using npm:

```shell
npm install -g @anthropic-ai/claude-code
```

### Step 2: Configure environment variables

Claude Code requires an API key to run. Set the following environment variables:

```shell
# Set the API key (required)
export ANTHROPIC_API_KEY="your-api-key-here"

# Set the API base URL (if using a proxy or custom endpoint)
export ANTHROPIC_BASE_URL="https://api.anthropic.com"
```

:::info

You can add these environment variables to `~/.bashrc`, `~/.zshrc`, or other shell configuration files to persist the settings.

:::

### Step 3: Configure network settings

Since the seekdb skill plugin needs to fetch the latest documentation from GitHub, you need to configure Claude Code to allow network requests in your project directory.

Create or edit the `.claude/settings.local.json` file in your project's root directory:

```shell
{
  "skipWebFetchPreflight": true
}
```

:::info

Setting `skipWebFetchPreflight` to `true` skips the preflight checks for network requests, allowing Claude Code to directly access remote documentation.
If GitHub is inaccessible, the plugin will automatically fall back to using local documentation.

:::

### Step 4: Install the seekdb plugin

After starting Claude Code, execute the following commands:

1. Add the seekdb plugin market

    ```shell
    /plugin marketplace add oceanbase/seekdb-ecology-plugins
    ```

2. Install the seekdb plugin

    ```shell
    /plugin install seekdb-plugin@seekdb
    ```

3. Restart Claude Code

After installation, you need to restart Claude Code to ensure the plugin is correctly loaded.

## Troubleshooting

### The plugin is not working

1. Verify the plugin installation: Run the `/plugin` command in Claude Code to confirm that `seekdb-plugin` is installed.
2. Restart Claude Code: Completely close and reopen the Claude Code terminal session.
3. Check the environment variables: Ensure that `ANTHROPIC_API_KEY` is correctly set.

### Unable to fetch remote documentation

1. Check your network connection: Ensure that you can access GitHub.
2. Check the configuration file: Confirm that `"skipWebFetchPreflight": true` is set in the `.claude/settings.local.json` file.
3. Use local documentation: If the network is unavailable, the plugin will automatically use local documentation.

### Update the plugin

To update to the latest version:

```shell
/plugin
```

Select "Manage marketplaces" and then select the seekdb marketplace, and press the u key to update.
