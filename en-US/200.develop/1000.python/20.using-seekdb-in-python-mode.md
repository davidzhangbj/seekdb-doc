# Try Embedded with Python

seekdb provides an embedded product form, allowing it to be integrated as a library into your applications. This offers developers a more powerful and flexible data management solution, making data management ubiquitous across various platforms such as microcontrollers, IoT devices, edge computing, mobile applications, and data centers. You can quickly leverage the seekdb All-in-one capabilities (TP, AP, AI Native).

![python](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/seekdb-python.png)

## Installation and configuration

### Environment requirements

* Supported operating systems: Linux (glibc >= 2.28)

* Supported Python versions: CPython 3.8 ~ 3.14

* Supported system architectures: x86_64, aarch64

You can run the following command to check whether your environment meets the requirements.

```python
python3 -c 'import sys;import platform; print(f"Python: {platform.python_implementation()} {platform.python_version()}, System: {platform.system()} {platform.machine()}, {platform.libc_ver()[0]}: {platform.libc_ver()[1]}");'
```

The return result is as follows:

```python
Python: CPython 3.8.17, System: Linux x86_64, glibc: 2.32
```

### Installation

You can use pip to install pylibseekdb. The default Python version and platform are automatically identified.

```python
pip install pylibseekdb
# Or specify an installation source to accelerate the installation
pip install pylibseekdb -i https://pypi.tuna.tsinghua.edu.cn/simple
```

If your pip version is low, you need to upgrade pip before installation:

```bash
pip install --upgrade pip
```

### Try seekdb

After you install seekdb, you can try it.

#### Considerations

* Multi-statement queries are not supported. By default, only the first statement is executed. Example:

  ```python
  cur.execute("insert into t1 values(100);insert into t1 values(200)")
  ```

* The tmpfs file system cannot be used as the database directory.
* Only streaming query mode is supported. Example:

  ```python
  cur = con.cursor()
  cur.execute("select * from t1")
  cur.fetchall()
  ```
* The execute method does not support parameterized queries.

#### Try basic operations of seekdb

The following example shows how to create a database, connect to the database, create a table, write data, and query data.

:::info
  For more information about the full syntax of seekdb, see <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003977879">SQL syntax</a>.
:::

seekdb provides the `test` database by default. The following example shows how to open the `test` database using default parameters, connect to it, and perform operations such as table creation, data writing, transaction commit, query, and secure database shutdown.

```python
import pylibseekdb

# Open the default database directory seekdb
pylibseekdb.open()
# Connect to the default test database
conn = pylibseekdb.connect()
# Create a cursor for data operations
cursor = conn.cursor()

# Execute a table creation statement
cursor.execute("create table t1(c1 int primary key, c2 int)")
# Execute data insertion
cursor.execute("insert into t1 values(1, 100)")
cursor.execute("insert into t1 values(2, 200)")
# Manually commit the transaction
conn.commit()

# Execute a query
cursor.execute("select * from t1")
# Retrieve the results
print(cursor.fetchall())

# Close the connection
cursor.close()
conn.close()
```

You can also manually specify the database directory and create and use a new database.

```python
import pylibseekdb

# Specify the database directory
pylibseekdb.open("mydb")
# Connect to no database
conn = pylibseekdb.connect("")
# Create a cursor for data operations
cursor = conn.cursor()
# Manually create a database
cursor.execute("create database db1")
# Use the newly created database
cursor.execute("use db1")

# Close the connection
cursor.close()
conn.close()
```

The following example shows how to enable automatic transaction commit mode.

```python
import pylibseekdb

# Specify the database directory
pylibseekdb.open("seekdb")
# Connect to the test database
conn = pylibseekdb.connect(database="test", autocommit=True)
# Create a cursor for data operations
cursor = conn.cursor()

# Execute a table creation statement
cursor.execute("create table t2(c1 int primary key, c2 int)")
# Execute data insertion with automatic transaction commit
cursor.execute("insert into t2 values(1, 100)")
# Execute data insertion with automatic transaction commit
cursor.execute("insert into t2 values(2, 200)")

# Query data using the new connection
conn2 = pylibseekdb.connect("test")
cursor2 = conn2.cursor()
cursor2.execute("select * from t2")
# View data row by row
print(cursor2.fetchone())
print(cursor2.fetchone())

# Close the connection
cursor.close()
conn.close()
cursor2.close()
conn2.close()
```

## Try seekdb

### Experience AI Native

#### Try vector search

seekdb supports dense vectors of up to 16,000 dimensions of the Float type, sparse vectors, and various types of vector distance calculations, such as Manhattan distance, Euclidean distance, inner product, and cosine distance. It also supports the creation of vector indexes based on HNSW/IVF, incremental updates, and deletions. Importantly, incremental updates and deletions do not affect the recall rate.

:::info
  For more information about vector search in seekdb, see <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003976682">Vector search</a>.
:::

The following example demonstrates how to use vector search in seekdb.

```python
import pylibseekdb

pylibseekdb.open("seekdb")
conn = pylibseekdb.connect("test")
cursor = conn.cursor()

# Create a table with a vector index
cursor.execute("create table test_vector(c1 int primary key, c2 vector(2), vector index idx1(c2) with (distance=l2, type=hnsw, lib=vsag))")

# Insert data
cursor.execute("insert into test_vector values(1, [1, 1])")
cursor.execute("insert into test_vector values(2, [1, 2])")
cursor.execute("insert into test_vector values(3, [1, 3])")
conn.commit()

# Execute vector search
cursor.execute("SELECT c1,c2 FROM test_vector ORDER BY l2_distance(c2, '[1, 2.5]') APPROXIMATE LIMIT 2;")
# Retrieve results
print(cursor.fetchall())

# Close the connection
cursor.close()
conn.close()
```

#### Try full-text search

seekdb provides full-text indexing capabilities. By building full-text indexes, you can comprehensively index entire documents or large segments of text. This significantly improves query performance when dealing with large volumes of text data and complex search requirements, enabling users to efficiently retrieve the information they need.

The following example demonstrates how to use the full-text search feature in seekdb.

```python
import pylibseekdb

pylibseekdb.open("seekdb")
conn = pylibseekdb.connect("test")
cursor = conn.cursor()

# Create a table with a full-text index
sql='''create table articles (title VARCHAR(200) primary key, body Text,
    FULLTEXT fts_idx(title, body));
    '''
cursor.execute(sql)

# Insert data
sql='''insert into articles(title, body) values
    ('OceanBase Tutorial', 'This is a tutorial about OceanBase Fulltext.'),
    ('Fulltext Index', 'Fulltext index can be very useful.'),
    ('OceanBase Test Case', 'Writing test cases helps ensure quality.')
    '''
cursor.execute(sql)
conn.commit()

# Execute full-text search
sql='''select
	title,
  match (title, body) against ("OceanBase") as score
from
	articles
where
	match (title, body) against ("OceanBase")
order by
	score desc
    '''
cursor.execute(sql)
# Retrieve results
print(cursor.fetchall())

# Close the connection
cursor.close()
conn.close()
```

#### Try hybrid search

Hybrid search combines vector-based semantic search with keyword search based on full-text indexes to provide more accurate and comprehensive search results through integrated sorting. Vector search excels at semantic approximate matching but is less effective at matching exact keywords, numbers, and proper nouns. Full-text search effectively compensates for this limitation. As a result, hybrid search has become one of the key features of vector databases and is widely used in various products.

seekdb provides hybrid search capabilities for multi-mode data based on SQL+AI. It allows you to perform integrated queries on multiple types of data within a single database system.

The following example demonstrates how to use the hybrid search feature of seekdb.

```python
import pylibseekdb

pylibseekdb.open("seekdb")
conn = pylibseekdb.connect("test")
cursor = conn.cursor()

# Create a table with vector and full-text indexes
cursor.execute("create table doc_table(c1 int, vector vector(3), query varchar(255), content varchar(255), vector index idx1(vector) with (distance=l2, type=hnsw, lib=vsag), fulltext idx2(query), fulltext idx3(content))")

# Insert data
sql = '''insert into doc_table values(1, '[1,2,3]', "hello world", "oceanbase Elasticsearch database"),
                            (2, '[1,2,1]', "hello world, what is your name", "oceanbase mysql database"),
                            (3, '[1,1,1]', "hello world, how are you", "oceanbase oracle database"),
                            (4, '[1,3,1]', "real world, where are you from", "postgres oracle database"),
                            (5, '[1,3,2]', "real world, how old are you", "redis oracle database"),
                            (6, '[2,1,1]', "hello world, where are you from", "starrocks oceanbase database");'''
cursor.execute(sql)
conn.commit()

sql = '''set @parm = '{
      "query": {
        "bool": {
          "must": [
            {"match": {"query": "hi hello"}},
            {"match": { "content": "oceanbase mysql" }}
          ]
        }
      },
       "knn" : {
          "field": "vector",
          "k": 5,
          "num_candidates": 10,
          "query_vector": [1,2,3],
          "boost": 0.7
      },
      "_source" : ["query", "content", "_keyword_score", "_semantic_score"]
    }';'''
cursor.execute(sql)

# Execute hybrid search
sql = '''select dbms_hybrid_search.search('doc_table', @parm);'''
cursor.execute(sql)
# Retrieve the results
print(cursor.fetchall())

# Close the connection
cursor.close()
conn.close()
```

### Experience analysis capabilities (OLAP)

seekdb integrates transaction processing (TP) with analytical processing (AP). Leveraging the LSM-Tree architecture, it unifies row and column storage. Additionally, it introduces a new vectorized engine and cost estimation model based on columnar storage, significantly improving the efficiency of wide table processing and query performance in AP scenarios. It also supports real-time import, secondary indexing, and high-concurrency primary key queries, meeting common requirements for real-time OLAP.

#### Experience data import

seekdb supports various flexible data import methods, allowing you to import data from multiple data sources into the database. Different import methods are suitable for different scenarios. You can choose the appropriate data import tool based on the data source type and business scenario. As scenarios become more complex and diverse, multiple import methods can be used together. When importing data, factors such as the data source, data file format, and support for the data import tool are considered. If the business scenario clearly specifies the data source and data file format, the data import plan should be designed based on the data source and in combination with the data import tool. If the business has a proficiently used data import tool, the support for the tool should be considered, and the data import possibility should be evaluated based on the business scenario.

The following example demonstrates how to quickly import `csv` data into seekdb using the `load data` method.

1. Create an external data source.

    ```bash
    cat /data/1/example.csv
    1,10
    2,20
    3,30
    ```

2. Import the external data in embedded mode.

    ```python
    import pylibseekdb

    pylibseekdb.open("seekdb")
    conn = pylibseekdb.connect("test")
    cursor = conn.cursor()

    # Create a table.
    cursor.execute("create table test_olap(c1 int, c2 int)")
    # Execute a fast import.
    cursor.execute("load data /*+ direct(true, 0) */ infile '/data/1/example.csv' into table test_olap fields terminated by ','")
    # Query data.
    cursor.execute("select count(*) from test_olap")
    # Obtain the result.
    print(cursor.fetchall())

    # Close the connection.
    cursor.close()
    conn.close()
    ```

#### Experience columnar storage

In scenarios involving large-scale data analysis or ad-hoc queries on massive data, columnar storage is one of the key capabilities of an AP database. The storage engine of seekdb, which supports row-based storage, has been enhanced to support columnar storage. This enables a unified storage solution where both columnar and row-based data coexist within a single codebase, architecture, and instance.

The following example demonstrates how to create a columnar storage table in seekdb.

```python
import pylibseekdb

pylibseekdb.open("seekdb")
conn = pylibseekdb.connect("test")
cursor = conn.cursor()

# Create a columnar storage table.
sql='''create table each_column_group (col1 varchar(30) not null, col2 varchar(30) not null, col3 varchar(30) not null, col4 varchar(30) not null, col5 int)
    with column group (each column);
    '''
cursor.execute(sql)

# Write data.
sql='''insert into each_column_group values('a', 'b', 'c', 'd', 1)
    '''
cursor.execute(sql)
conn.commit()

# Execute a query.
cursor.execute("select col1,col2 from each_column_group")

# Obtain the result.
print(cursor.fetchall())

# Close the connection.
cursor.close()
conn.close()
```

#### Experience materialized views

Materialized views (MVs) are a key feature that supports AP business. They reduce the need for real-time computation by precomputing and storing the results of view queries, thereby improving query performance and simplifying complex query logic. Materialized views are commonly used in scenarios such as rapid report generation and data analysis. seekdb supports both non-real-time and real-time materialized views. You can specify a primary key or create an index for a materialized view. Additionally, seekdb introduces nested materialized views, which can further enhance query performance.

The following example demonstrates how to use materialized views in seekdb.

```python
import pylibseekdb
import time

pylibseekdb.open("seekdb")
conn = pylibseekdb.connect("test")
cursor = conn.cursor()

# Create base tables.
cursor.execute("create table base_t1(a int primary key, b int)")
cursor.execute("create table base_t2(c int primary key, d int)")

# Create materialized view logs.
cursor.execute("create materialized view log on base_t1 with(b)")
cursor.execute("create materialized view log on base_t2 with(d)")

# Create a materialized view named mv based on the base tables base_t1 and base_t2. Specify the refresh strategy as incremental refresh and set the initial refresh time to the current date, with subsequent refreshes occurring every 1 second.
cursor.execute("create materialized view mv REFRESH fast START WITH sysdate() NEXT sysdate() + INTERVAL 1 second as select a,b,c,d from base_t1 join base_t2 on base_t1.a=base_t2.c")

# Write data to the base tables.
cursor.execute("insert into base_t1 values(1, 10)")
cursor.execute("insert into base_t2 values(1, 100)")
conn.commit()

# Wait for the background refresh of the materialized view to complete.
time.sleep(10)

# Query data.
cursor.execute("select * from mv")
# Obtain the result.
print(cursor.fetchall())

# Close the connection.
cursor.close()
conn.close()
```

#### Access external tables

Usually, table data is stored in the storage space of a database, while external table data is stored in an external storage service. When you create an external table, you need to define the path and format of the data files. After the external table is created, you can read data from the external storage service through the external table.

The following example shows how to access an external `csv` file using the external table feature of seekdb.

1. Create an external data source

    ```bash
    cat /data/1/example.csv
    1,10
    2,20
    3,30
    ```

2. Access external table data in embedded mode

    ```python
    import pylibseekdb

    pylibseekdb.open("seekdb")
    conn = pylibseekdb.connect("test")
    cursor = conn.cursor()

    # Create an external table
    sql='''CREATE EXTERNAL TABLE test_external_table(c1 int, c2 int) LOCATION='/data/1' FORMAT=(TYPE='CSV' FIELD_DELIMITER=',') PATTERN='example.csv';
    '''
    cursor.execute(sql)

    # Query data
    cursor.execute("select * from test_external_table")

    # Get the results
    print(cursor.fetchall())

    # Close the connection
    cursor.close()
    conn.close()
    ```

### OLTP

The following example shows the transaction capability of SeekDB.

```python
import pylibseekdb

pylibseekdb.open("seekdb")
conn = pylibseekdb.connect("test")
cursor = conn.cursor()

# Create a table.
cursor.execute("create table test_oltp(c1 int primary key, c2 int)")

# Write data.
cursor.execute("insert into test_oltp values(1, 10)")
cursor.execute("insert into test_oltp values(2, 20)")
cursor.execute("insert into test_oltp values(3, 30)")
# Commit the transaction.
conn.commit()

# Query data. ORA_ROWSCN indicates the data version number.
cursor.execute("select *,ORA_ROWSCN from test_oltp")
# Obtain the query result.
print(cursor.fetchall())

# Close the connection.
cursor.close()
conn.close()
```

## Smoothly switch to the distributed version

After you verify the product prototype in the embedded version, you can switch to the seekdb Server mode or use the cluster processing capabilities of OceanBase Database. You only need to modify the import package and related configurations, while the core application logic remains unchanged.

```python
import pylibseekdb
pylibseekdb.open()
conn = pylibseekdb.connect()
```

Modify the three lines above to the two lines below. Replace pylibseekdb with pymysql, remove the open phase of pylibseekdb, and use the connect method of pymysql to connect to the database server.

```python
import pymysql
conn = pymysql.connect(host='127.0.0.1', port=11002, user='root@sys', database='test')
```
