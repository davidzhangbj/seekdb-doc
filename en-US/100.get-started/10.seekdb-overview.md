# What is seekdb

OceanBase seekdb (referred to as seekdb) is a next-generation, developer-friendly database product from OceanBase, designed to deliver efficient hybrid search capabilities for AI applications. It provides unified storage and retrieval for vector, full-text, and multi-model data. Building on OceanBase's high-performance core engine and full MySQL compatibility, seekdb offers deeply optimized data search architecture, providing developers with solutions that better meet the data processing needs of AI applications.

## Product architecture

![seekdb-arch](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/seekdb-arch.jpg)

* Deployment modes: seekdb supports both embedded and server deployments. The embedded mode allows seamless integration into Python applications, making it especially convenient for individual developers.

* Multi-model data and indexing layer: seekdb accommodates a wide range of data types, including vectors, text, JSON, and GIS, and provides robust indexing capabilities. It features HNSW/IVF vector indexes and quantization algorithms, full-text indexes based on BM25 relevance that support various tokenizers and query modes, hybrid indexes for mixed search scenarios, JSON indexes for metadata searches, as well as primary, secondary, and GIS indexes.

* Multi-model compute layer for hybrid workloads: seekdb enables hybrid searches across vectors, full-text, and scalar conditions, enhancing the accuracy of query results in Retrieval-Augmented Generation (RAG) scenarios. It offers built-in AI function capabilities for real-time inference within the database. seekdb supports full ACID transactions and multi-version concurrency control (MVCC), along with a query optimizer designed for hybrid workloads, an adaptive execution engine, and flexible PL UDF functions to address diverse business needs.

* Unified application interface: seekdb is compatible with native MySQL drivers and provides a unified SQL-based query language for multi-model data. Additionally, it offers developer-friendly SDKs for vector databases and hybrid search. seekdb integrates with nearly 30 application development frameworks, including popular AI frameworks such as LangChain, LlamaIndex, and Dify, and features an MCP server for seamless connection to the AI ecosystem.

## Applicable scenarios

### RAG applications

For RAG scenarios like intelligent chatbots, knowledge bases, and expert systems, seekdb delivers a complete RAG pipeline solution. This includes document parsing, vector embedding, result reranking, and seamless interaction with large language models (LLMs). seekdb supports hybrid searches that combine vector, full-text, and scalar queries, enabling true end-to-end processing—everything from document input to data output happens within a single database instance. For example, in a knowledge base setting, seekdb can quickly retrieve factual information to provide LLMs with accurate, real-time data. This not only boosts the precision of generated content but also makes the generation process easier to interpret.

### AI-assisted programming

seekdb is well-suited for AI-powered programming tasks. It can build vector and full-text indexes for code repositories, making it easy to search for code or generate completions based on keywords or code semantics. seekdb also excels at organizing code data, supporting both structured storage (like syntax trees and dependency graphs) and unstructured storage (such as raw code text). Its dynamic metadata management allows developers to flexibly extend and efficiently query code attributes—like language type, function names, and parameter lists.

### AI agent platform applications

seekdb offers an all-in-one data solution for building AI agents. It supports rapid startup and embedded deployment, so services can be launched quickly to meet agile development needs. The high-performance engine handles frequent data updates and real-time queries with ease, eliminating database bottlenecks that can slow down AI development. With built-in vector, full-text, and hybrid search, flexible metadata and session management, and integrated memory storage, developers can build robust AI agents without needing extra libraries—reducing both system complexity and the learning curve.

### Semantic search engines

seekdb provides a comprehensive vector search solution for semantic search scenarios, including e-commerce product search, multimedia retrieval, image search, and facial recognition. It works with popular vector embedding models to store text or image features as vectors, and uses high-performance indexing for fast similarity searches. The semantic index feature simplifies development even further: users just submit a text query, and seekdb automatically handles vector embedding and reranking behind the scenes. This lowers the barrier to integrating AI with databases, making semantic search easier and more efficient.

### Modernizing MySQL applications with AI capabilities

seekdb builds on OceanBase's powerful storage, execution, transaction, and query optimization engines, and is highly compatible with MySQL. On top of this, it adds advanced AI capabilities. Smaller deployments are ideal for IoT edge data collection, lightweight app development, and educational experiments, while medium and large deployments can support OLTP, HTAP, or AI workloads across a wide range of industries.

## Core features

### Instant Setup, fast development, and easy to use

seekdb's single-node architecture makes installation and configuration quick and simple. There are no extra dependencies—just start it up and you are ready to go, which is highly suitable for agile AI development. You can deploy seekdb flexibly, either as a server or embedded within your application. For server deployment, options include yum install, Docker, or desktop versions for Windows and macOS. For embedded use, seekdb integrates natively with Python, making it a seamless choice as an in-app database for AI projects. With built-in support for popular AI development frameworks, you can get your AI application up and running in minutes.

### 1C2G support with vertical scalability

seekdb can run the VectorDBBench Performance1536D50K benchmark on just 1 CPU core and 2 GB of memory (1C2G). When higher concurrency, larger datasets, or more complex queries are required, resources can be scaled vertically to meet increased demands.

### High-performance vector and full-text indexing with hybrid search

* Vector search: Supports storage and high-speed retrieval of vectors with up to 16,000 dimensions, compatible with L2, inner product, cosine similarity, and more. Provides HNSW/IVF indexing and quantization algorithms for both precise and approximate nearest neighbor searches, addressing diverse AI retrieval requirements.

* Full-text search: Delivers robust full-text indexing based on the BM25 relevance ranking algorithm for accurate keyword searches. seekdb supports multiple tokenizers—including Space, Beng, Ngram, IK, and Jieba—and a variety of query modes such as natural language, boolean, phrase, and multi-match, enabling efficient retrieval of relevant text from large datasets.

* Hybrid search: Enables combined searches across vector, full-text, scalar, and spatial data. A single SQL query can perform multiple search types and reranking, significantly enhancing the accuracy of RAG application results.

### Semantic search powered by semantic index

seekdb's semantic index feature automatically embeds text data and generates vector indexes as soon as the data is written. To perform semantic searches, simply specify the text search condition, and the system will process the query using semantic matching. This approach hides the complexity of vector embedding and reranking, simplifying database interactions for AI applications.

### Seamless integration with various models and built-in AI functions for real-time inference

seekdb supports integration with large language models and vector embedding models through the `DBMS_AI_SERVICE` system package for model registration and management. Built-in AI functions such as `AI_COMPLETE`, `AI_PROMPT`, `AI_EMBED`, and `AI_RERANK` allow data embedding and real-time inference directly within the database using standard SQL syntax.

### Dynamic JSON-based schema for flexible metadata storage and efficient access

seekdb supports JSON data types and dynamic schemas. Partial updates to JSON data help reduce update costs, and JSON function indexes and multi-value indexes optimize query performance. Semi-structured encoding lowers storage costs. In AI applications, JSON is ideal for storing document metadata and supports hybrid search with full-text and vector data.

### Real-time data ingestion and immediate querying

Built on an LSM-tree storage architecture, seekdb supports high-frequency, real-time data writes. As data is inserted, full-text, vector, and scalar indexes are built synchronously, making new data instantly available for queries.

### Beyond MySQL compatibility: supporting HTAP workloads

seekdb is deeply compatible with MySQL syntax, protocols, and data dictionaries, ensuring seamless migration for MySQL applications. Its innovative architecture extends beyond traditional MySQL capabilities by supporting hybrid row-column storage and vectorized execution. A single instance can handle both online transaction processing and real-time analytics, eliminating delays and maintenance costs associated with data synchronization.
