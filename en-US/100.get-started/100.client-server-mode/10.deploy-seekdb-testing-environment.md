# Deploy a seekdb testing environment

seekdb provides both embedded and server deployment modes. You can choose the appropriate mode based on your business requirements. This topic describes how to quickly deploy a testing environment for seekdb in server mode.

:::info
For more information about how to use seekdb in embedded mode, see [Experience embedded seekdb](../50.embedded-mode/25.using-seekdb-in-python-sdk.md).
:::

## Deployment modes

seekdb provides flexible deployment modes to meet your application requirements, from rapid prototyping to supporting a large number of users.

* Embedded mode

    seekdb is embedded as a lightweight library in your application and supports one-click installation via pip. It is suitable for personal learning, rapid prototyping, and efficient operation on various edge devices.

* Server mode

    This mode is recommended for testing and production environments. It is lightweight and easy to use, making it ideal for stable and efficient service delivery.

:::info
For more detailed and comprehensive deployment options, see [Overview of deployment](../../400.guides/400.deploy/50.deploy-overview.md).
:::

## Prerequisites

Before you start the deployment, make sure that your environment meets the following requirements:

* Your environment is an RPM-based system. The following systems have been verified to be supported.

  * Anolis OS 8.X (Linux kernel 3.10.0 or later)
  * Alibaba Cloud Linux 2/3 (Linux kernel 3.10.0 or later)
  * Red Hat Enterprise Linux Server 7.X and 8.X (Linux kernel 3.10.0 or later)
  * CentOS Linux 7.X and 8.X (Linux kernel 3.10.0 or later)
  * Debian 9.X and later (Linux kernel 3.10.0 or later)
  * Ubuntu 20.X and later (Linux kernel 3.10.0 or later)
  * SUSE / OpenSUSE 15.X and later (Linux kernel 3.10.0 or later)
  * openEuler 22.03 and 24.03 (Linux kernel 5.10.0 or later)
  * KylinOS V10
  * UnionTech UOS 1020a/1021a/1021e/1001c
  * NFSChina 4.0 and later
  * Inspur KOS 5.8

* Your environment has at least 1 CPU core.

* Your environment has at least 2 GB of available memory.

* Your environment has a database connection tool installed, such as MySQL client or OBClient client.

* The user you use has sudo privileges.

* The conditions required for deployment by using yum install

  * The jq command-line tool is installed in your environment, and systemd is correctly configured as the system and service manager.

* The conditions required for deployment by using Docker

  * Docker is installed and running.

## Quickly deploy seekdb by using yum install

1. Add the seekdb image source.

    ```shell
    [admin@test001 ~]$ sudo yum-config-manager --add-repo https://mirrors.aliyun.com/oceanbase/OceanBase.repo
    ```

2. Install seekdb.

    ```shell
    [admin@test001 ~]$ sudo yum install seekdb obclient
    ```

3. Start seekdb.

    ```shell
    [admin@test001 ~]$ sudo systemctl start seekdb
    ```

4. Check the status of seekdb.

    ```shell
    [admin@test001 ~]$ sudo systemctl status seekdb
    ```

    If the status is `Service is ready`, seekdb has been started normally.

5. Connect to seekdb.

    ```shell
    mysql -h127.0.0.1 -uroot -P2881 -A oceanbase
    ```

## Quickly deploy a seekdb container environment

If Docker is installed and running in your environment, you can also deploy seekdb in a Docker container. For more information about Docker deployment, see [Deploy a seekdb container environment](../../400.guides/400.deploy/700.server-mode/200.deploy-by-docker.md).

1. Start a seekdb instance.

    ```shell
    [admin@test001 ~]$ sudo docker run -d -p 2881:2881 oceanbase/seekdb
    ```
    :::info
      If the Docker image pull fails, you can also pull the image from the quay.io or ghcr.io repositories. To do so, replace <code>oceanbase/seekdb</code> in the pull command with <code>quay.io/oceanbase/seekdb</code> or <code>ghcr.io/oceanbase/seekdb</code>, as in the following example: <code>sudo docker run -d -p 2881:2881 quay.io/oceanbase/seekdb</code>.
    :::

2. Connect to seekdb.

    ```shell
    mysql -h127.0.0.1 -uroot -P2881 -A oceanbase
  	```
