## Version overview

OceanBase seekdb (short for seekdb) is an AI-native hybrid search database that integrates vector, text, structured, and semi-structured data capabilities in a single database. It supports multi-modal hybrid search and intelligent reasoning through built-in AI functions.

### Product architecture

![seekdb-arch](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/overview/seekdb-arch.png)

* Deployment mode: Supports embedded and server deployment modes. In embedded mode, seekdb can be directly integrated into Python applications, facilitating personal development.

* Multi-modal data and index layer: Supports vector, text, JSON, GIS, and other multi-modal data types, with efficient indexing capabilities. Includes HNSW/IVF vector indexes and index quantization algorithms, BM25-based full-text indexes for various tokenizers and query modes, hybrid indexes for multi-modal search, JSON indexes for metadata search, and supports primary and secondary indexes, GIS indexes, etc.

* Multi-modal computing layer for mixed workloads: Supports hybrid search based on vector, full-text, and scalar conditions to improve query accuracy in RAG scenarios. Provides AI functions for real-time inference within the database. Supports complete ACID transactions and concurrent access with multi-version concurrency control (MVCC). Offers a query optimizer, adaptive execution engine, and flexible PL UDFs to meet diverse business needs.

* Unified application interface: Compatible with MySQL native drivers, providing a unified query language for multi-modal data based on SQL. Implements a user-friendly vector database and hybrid search SDK for developers. Adapts to nearly 30 application development frameworks, including LangChain, LlamaIndex, and Dify. Provides MCP Server for seamless integration into AI ecosystems.

## Core advantages

* Rapid development

  Build AI applications with just a few lines of Python code. The lightweight architecture runs VectorDBBench on 1C2G.

* Hybrid search

  Completes vector, full-text, and scalar filtering in a single query, supporting multi-stage search pipelines with coarse and fine ranking.

* Multi-modal data and indexes

  Supports scalar, vector, text, JSON, GIS, and other multi-modal data and indexes within a single engine.

* AI-native

  Completes vector embedding, inference, prompt management, and re-ranking within the database, supporting the complete RAG workflow from document-in to data-out.

* Native SQL

  Built on the mature OceanBase engine, supports real-time writing and querying, ACID transactions, and is compatible with the MySQL ecosystem.

## AI-native

Empowers AI application development from search to inference.

### Hybrid search

* Supports vector-based semantic recall and keyword-based recall in a single SQL query, with optimized multi-stage recall.
* Query re-ranking supports weights, RRF, and large model-based re-ranking.
* Optimizes scalar filter pushdown to storage and supports multi-table join searches.

### Vector & full-text search

* Supports dense and sparse vectors, with various distance metrics including Manhattan, Euclidean, inner product, and cosine.
* Vector indexes support in-memory HNSW, HNSW-SQ, HNSW-BQ, and disk-based IVF, IVF-PQ, optimizing storage costs.
* Full-text search supports keyword, phrase, and boolean matching, with BM25 sorting.

### AI functions

* `DBMS_AI_SERVICE` manages built-in large model services via SQL and supports registering external services.
* `AI_EMBED` converts text to vector embeddings in SQL.
* `AI_COMPLETE` generates text in SQL using prompt templates.
* `AI_RERANK` sorts text using large model-based re-ranking in SQL.

## Use cases

### RAG & knowledge retrieval enhancement

Large models are limited by training data, so RAG introduces real-time, accurate external knowledge sources to improve answer quality and reduce hallucinations. seekdb provides high-precision search through vector search, full-text search, hybrid search, built-in AI functions, and efficient indexing, with multi-level permission controls to ensure privacy and security of multi-source knowledge bases.

Use cases:
* Enterprise knowledge base Q&A
* Intelligent customer service
* Industry information retrieval
* Personal knowledge assistant

### AI-assisted programming

seekdb supports building vector and full-text indexes for code repositories, enabling efficient code search and generation based on keywords or semantics. It also provides efficient data organization capabilities for structured storage (e.g., syntax trees, dependency graphs) and unstructured storage (e.g., raw code text), with dynamic metadata management for flexible extension and efficient querying of code attributes (e.g., language type, function names, parameter lists).

### Semantic search engine

Traditional search relies on keyword matching, making it hard to understand real intent. Semantic search uses embeddings and vector search to understand query semantics and supports multi-modal associations like text and images. seekdb's hybrid search and multi-model queries make search more accurate and intelligent.

Use cases:
* Product search and recommendations
* Image search by text
* Text search by image

### Agentic AI applications

Agentic AI can make active decisions, plan tasks, and perceive environments. seekdb provides a one-stop solution for agent applications, including metadata management, memory storage, multi-model data queries, multi-modal data processing, retrieval-augmented generation, built-in AI functions and inference, and data privacy controls.

Use cases:
* Personal life assistant
* Enterprise automation
* Industry-specific agents
* Agent development platform

### AI-driven intelligent programming

AI programming uses natural language understanding and code semantics to generate, complete, fix, and test code. seekdb improves code generation quality with semantic search, manages code and documents with multi-model storage, and supports multi-project and version management through multi-level isolation and flashback queries, adapting to local and cloud development.

Use cases:
* IDE coding plugins
* Design draft to web
* Local intelligent IDE
* Web-based IDE

### Enterprise AI upgrade

AI upgrades enterprise applications from passive execution to active collaboration. seekdb provides AI application storage solutions, is highly compatible with MySQL syntax and views, and offers high-performance hybrid workload processing through parallel execution and hybrid storage (row and column) technologies. This allows traditional systems to gain AI capabilities without major migrations, covering all scenarios from office to operations.

Use cases:
* Intelligent document processing
* Business insights
* Financial management systems

### Edge AI and device intelligence

Mobile phones, car infotainment systems, and industrial gateways use low-power processors and small storage capacities compared to data centers and cloud servers. seekdb's lightweight architecture supports embedded or lightweight server modes, providing complete SQL, JSON, and hybrid search capabilities with minimal resource usage, seamlessly integrating with OceanBase cloud services to build intelligent systems.

Use cases:
* Personal intelligent assistants
* Intelligent car terminals
* AI tutoring
* AI companions
* Smart medical devices
