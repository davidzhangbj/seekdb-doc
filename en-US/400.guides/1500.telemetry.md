# Telemetry

seekdb has built-in telemetry functionality, which is enabled by default. This feature collects anonymous usage data to help us understand how users interact with seekdb, identify common issues, and continuously improve our product features and user experience.

## Privacy protection

The telemetry feature anonymizes sensitive information, such as IP addresses, using hashing. It only collects necessary technical metrics and does not gather any business data or personal user information.

## Manage telemetry

You can enable or disable telemetry by setting the `TELEMETRY_ENABLED` environment variable.

To disable telemetry:

```bash
export TELEMETRY_ENABLED=false
```

To re-enable telemetry after it has been disabled:

```bash
export TELEMETRY_ENABLED=true
```

:::tip
Telemetry is enabled by default, so you don't need to manually set this environment variable. Set it to false only when you want to disable telemetry.
:::

## What information does telemetry collect?

Telemetry collects the following anonymized technical information:

* Version and deployment information: the version of seekdb and its deployment method.

* Host environment information: the operating system version, CPU model and number of cores, and memory capacity.

* Resource specifications: the memory, data disk, and log disk capacity configured for seekdb.

## View collected information

A local copy of the telemetry data is stored. You can view the specific information collected by seekdb in the `run/telemetry.json` file within the deployment directory.
