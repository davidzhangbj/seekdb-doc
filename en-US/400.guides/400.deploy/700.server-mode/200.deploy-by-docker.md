# Deploy seekdb in a Docker container

This topic describes how to deploy seekdb in a Docker container.

## Overview

You can obtain the `seekdb` Docker image from [dockerhub](https://hub.docker.com/r/oceanbase/seekdb), [quay.io](https://quay.io/repository/oceanbase/seekdb), or [ghcr.io](https://ghcr.io/oceanbase/seekdb). This image helps you quickly set up a seekdb environment for testing.

:::tip
  <ul><li>If you run this image on macOS or a computer with an Intel chip and your Docker version is higher than 4.9.0, a known issue may occur. You can download the required version of <a href="https://desktop.docker.com/mac/main/amd64/81317/Docker.dmg?_gl=17jelfd_gcl_auOTk5Nzk0MDUwLjE3MTE4ODMyNzM._gaNDQyMjE1MDE5LjE3MTE4ODMyNzQ._ga_XJWPQMJYHQ*MTcxOTIxOTEwMy4xMS4xLjE3MTkyMjEwMTAuNjAuMC4w">Docker</a> from this link.</li>
  <li>This image is only for testing purposes. Do not use it in a production environment.</li></ul>
:::

## Prerequisites

Before you deploy `seekdb`, make sure that the following conditions are met:

* You have installed and started Docker. For more information, see [Docker documentation](https://docs.docker.com/get-docker/).

* Your server has at least one physical core and 2 GB of memory.

## Start a seekdb instance

To start a seekdb instance, run the following command:

```shell
docker run -d -p 2881:2881 oceanbase/seekdb
```

:::info
  <ul>
  <li>
  If you fail to pull the Docker image, you can also pull it from the quay.io or ghcr.io repository. To do so, replace <code>oceanbase/seekdb</code> in the pull command with <code>quay.io/oceanbase/seekdb</code> or <code>ghcr.io/oceanbase/seekdb</code>, as shown in the following example: <code>sudo docker run -d -p 2881:2881 quay.io/oceanbase/seekdb</code>.
  </li>
  <li>
  By default, the preceding command pulls the latest version. You can select a version from <a href="https://hub.docker.com/r/oceanbase/seekdb">dockerhub</a>, <a href="https://quay.io/repository/oceanbase/seekdb">quay.io</a>, or <a href="https://ghcr.io/oceanbase/seekdb">ghcr.io</a> as needed.
  </li>
  </ul>
:::

If you want to execute an initialization SQL script after the instance is started, you need to mount a directory that contains the initialization script and specify the mounted directory in the container by using the `INIT_SCRIPTS_PATH` environment variable. Example command:

```shell
docker run -d -p 2881:2881 -v {init_sql_folder_path}:/root/boot/init.d -e INIT_SCRIPTS_PATH=/root/boot/init.d oceanbase/seekdb
```
  In the preceding command, `{init_sql_folder_path}` specifies the path of the initialization SQL script on the host server.

:::tip
  Do not change the password of the root user in the SQL script. If you want to change the password of the root user, use the <code>ROOT_PASSWORD</code> environment variable. Example: <code>docker run -d -p 2881:2881 -e ROOT_PASSWORD="******" oceanbase/seekdb</code>.
:::

The following table describes the supported environment variables.

| Variable | Description | Default value |
|-----------|-------------|-------|
| ROOT_PASSWORD           | The password of the root user. | Empty |
| CPU_COUNT               | The value of cpu_count. | 4 |
| MEMORY_LIMIT            | The value of memory_limit. | 2G |
| LOG_DISK_SIZE           | The value of log_disk_size. | 2G |
| DATAFILE_SIZE           | The value of datafile_size. | 2G |
| DATAFILE_NEXT           | The value of datafile_next. | 2G |
| DATAFILE_MAXSIZE        | The value of datafile_maxsize. | 50G |
| INIT_SCRIPTS_PATH       | The path of the initialization script in the container. | \ |

If you want to modify more seekdb parameters, you can deploy seekdb by using a configuration file.

You can mount the configuration file to the `/etc/oceanbase/seekdb.cnf` directory in the container.

1. Create a configuration file on the host server. The default configuration file is as follows.

  ```shell
  datafile_size=2G
  datafile_next=2G
  datafile_maxsize=50G
  cpu_count=4
  memory_limit=8G
  log_disk_size=2G
  # config the parameter in the following format
  # key=value
  ```

2. Start seekdb.

  ```shell
  docker run -d -p 2881:2881 -v {config_file}:/etc/oceanbase/seekdb.cnf oceanbase/seekdb
  ```

  In the preceding command, `{config_file}` specifies the path of the configuration file on the host server.

  :::tip
    If you decide to use a configuration file, do not specify resource-related environment variables.
  :::

## Data persistence

seekdb is deployed in the `/var/lib/oceanbase` directory. If you want to persist data to the host server, you can mount an empty directory on the host server to this directory.

```shell
mkdir -p seekdb
docker run -d -p 2881:2881 -v $PWD/seekdb:/var/lib/oceanbase --name seekdb oceanbase/seekdb
```

## Connect to a seekdb instance

You can use the OBClient or MySQL client on the host server to connect to a seekdb instance.

```shell
[admin@test001 ~]$ mysql -uroot -h127.0.0.1 -P2881 -p
```

:::info
  If you do not specify the password by using an environment variable when you start a seekdb instance, the password of the user created in the instance is empty by default.
:::

## Access the obshell dashboard

The obshell is also started in the container. It provides a user-friendly Web interface. You can also map the port of the obshell dashboard.

```shell
# 2886 is the port of the obshell dashboard.
docker run -d -p 2881:2881 -p 2886:2886  oceanbase/seekdb
```

You can go to `http://${server_ip}:2886` in your browser to access the obshell dashboard. The login password is the same as the password of the root user. If you do not specify the `ROOT_PASSWORD` environment variable, leave the password field empty.
