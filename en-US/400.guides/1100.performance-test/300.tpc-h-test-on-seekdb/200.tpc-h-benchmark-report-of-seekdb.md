# seekdb TPC-H benchmark report

This topic describes the test environment, test plan, and detailed test results of the TPC-H benchmark.

## Test plan

* Two machines are used for the test. TPC-H is deployed on one machine, and seekdb is deployed on the other. seekdb has 4 CPU cores and 8 GB of memory. The log disk, clog disk, and data disk are three separate disks, and the performance level is PL1.

* The test data size is 10 GB.

For more information about the test steps, see [seekdb TPC-H benchmark](200.tpc-h-benchmark-report-of-seekdb.md).

## Test environment

The test environment is an Alibaba Cloud ECS instance. seekdb is deployed on an ECS instance with 4 CPU cores and 8 GB of memory.

* When seekdb is deployed on an ECS instance with 4 CPU cores and 8 GB of memory, the corresponding hardware configuration and software version are as follows:

* Hardware configuration

  | Service type | ECS type | Number of instances | Number of CPU cores | Memory |

    | ------- | -------- | ----- | --------- | ---- |
    | seekdb | ecs.c8i.xlarge  | 1 | 4C | 8G |
    * Software version

  | Service type | Software version |

    | ------- | ------- |
    | seekdb | seekdb 1.0.1 |
    | TPC-H        | V3.0.0 |
    | OS              | CentOS Linux 7 (Core) |
