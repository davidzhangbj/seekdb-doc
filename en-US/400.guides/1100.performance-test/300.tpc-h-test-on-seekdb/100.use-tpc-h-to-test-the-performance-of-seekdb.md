# TPC-H test for seekdb

This topic describes how to use TPC-H tools to perform performance tests on seekdb.

## What is TPC-H

TPC-H (Transaction Processing Performance Council's Decision Support Benchmark) is a benchmark developed by the Transaction Processing Performance Council (TPC) to simulate decision support applications. It is widely used in both academia and industry to evaluate the performance of decision support technologies. This commercial benchmark comprehensively assesses a system's overall business computing capabilities, imposing higher demands on vendors while also holding significant practical value in various business contexts. It is extensively applied in areas such as credit analysis in banking, credit card analysis, telecommunications operations analysis, tax analysis, and decision-making in the tobacco industry.

TPC-H evolved from TPC-D, a standard established by TPC in 1994 for benchmarking decision support systems. TPC-H implements a data warehouse using Third Normal Form (3NF), consisting of eight fundamental relations. The primary metric for evaluating TPC-H benchmarks is the response time for each query, defined as the time taken from query submission to result return. The benchmark's measurement unit is Queries Per Hour at a specific database size (QphH@size), where QphH represents the average number of complex queries executed per hour by the system, and size denotes the database scale. This metric effectively reflects the system's query processing capabilities. TPC-H is modeled based on real production environments, enabling it to assess critical performance parameters that other benchmarks cannot. In summary, the TPC-H standard developed by TPC meets the testing needs of the data warehouse domain and drives vendors and research institutions to push the boundaries of this technology.

## Environment preparation

Before you perform the test, prepare the test environment as required:

* JDK: We recommend that you use JDK 1.8u131 or later.

* make: Run the `yum install make` command to install make.

* GCC: Run the `yum install gcc` command to install GCC.

* mysql-devel: Run the `yum install mysql-devel` command to install mysql-devel.

* Python database driver: Run the `sudo yum install MySQL-python` command to install the Python database driver.

* prettytable: Run the `pip install prettytable` command to install prettytable.

* JDBC: We recommend that you use `mysql-connector-java-5.1.47`.

* TPC-H Tool: Download the TPC-H Tool from [this link](https://www.tpc.org/tpc_documents_current_versions/download_programs/tools-download-request5.asp?bm_type=TPC-H&bm_vers=3.0.0&mode=CURRENT-ONLY).

* seekdb: We recommend that you use the server mode of seekdb. For more information about how to deploy seekdb in the server mode, see [Deploy seekdb in the server mode](../../400.deploy/700.server-mode/100.deploy-by-systemd.md).

* The log disk, clog disk, and data disk of the deployed seekdb must be three separate disks with the PL1 performance level. When you start seekdb, set the following parameters in the `/etc/oceanbase/seekdb.cnf` file:

```shell
   port=2881
   base-dir=/data/1/seekdb
   data-dir=/data/2/seekdb
   redo-dir=/data/3/seekdb
   ```

   ## Test plan

* Two machines are required for this test. TPC-H is deployed on one machine, and seekdb is deployed on another machine. The seekdb server has 4 CPU cores and 8 GB of memory. The server has three disks: a log disk, a clog disk, and a data disk. All disks are of the PL1 performance level.

* The test data volume is 10 GB.

### Step 5: Generate query SQL

Use the built-in tools of TPC-H to generate the query SQL. The steps are as follows:

1. Copy `dbgen/qgen` and `dbgen/dists.dss` to the `mysql_sql` folder.

2. Create a `gen.sh` script in the `mysql_sql` folder to generate the query SQL.

```bash
   vim gen.sh
   ```

   ```bash
   #!/usr/bin/bash
   for i in {1..22}
   do  
   ./qgen -d $i -s 10 > db"$i".sql
   done
   ```

   3. Modify the number of concurrent queries for the generated SQL statements.

For example, the modified SQL statement for `Q1` is as follows:

   ```sql

   SELECT /*+    parallel(4) */   ---Add the parallel clause to enable concurrent execution.
   l_returnflag,
   l_linestatus,
   sum(l_quantity) as sum_qty,
   sum(l_extendedprice) as sum_base_price,
   sum(l_extendedprice * (1 - l_discount)) as sum_disc_price,
   sum(l_extendedprice * (1 - l_discount) * (1 + l_tax)) as sum_charge,
   avg(l_quantity) as avg_qty,
   avg(l_extendedprice) as avg_price,
   avg(l_discount) as avg_disc,
   count(*) as count_order
   FROM
   lineitem
   WHERE
   l_shipdate <= date '1998-12-01' - interval '90' day
   GROUP BY
   l_returnflag,
   l_linestatus
   ORDER BY
   l_returnflag,
   l_linestatus;
   ```

### Step 7: Load data

You can generate a script based on the data and SQL statements generated in the preceding steps. The following example shows how to load data:

1. Create a script named `load_data.sh` to load data.

```bash

   #!/bin/bash
   host='$host_ip'   # Note: Please specify the IP address of the server where seekdb is located. We recommend that you also store the data files on this server.
   port='$host_port' # The port number of seekdb.
   user='$user'      # The username.
   password='$password'   # The password.
   database='$db_name'    # The database name.
   data_path='$data_file' # Note: Please specify the path of the .tbl file generated in the data generation step.
   function load_data

   {
   remote_user="$user"         # The username of the seekdb user who stores data.
      table_name=${1}
      if [[ ${password} == "" ]];then
      mysql_conn="mysql -h${host} -P${port} -u${user} -D${database} -A -c"
         else
      mysql_conn="mysql -h${host} -P${port} -u${user} -D${database} -p${password} -A -c"
         fi
      table_list=$(ssh "${remote_user}@${host}" "ls ${data_path}/${table_name}.tbl* 2>/dev/null")
      echo "$table_list"
      IFS=$'\n' read -d '' -r -a table_files <<< "$table_list"

      table_files_comma_separated=$(IFS=,; echo "${table_files[*]}")
      echo "${table_files_comma_separated}"
      echo `date "+[%Y-%m-%d %H:%M:%S]"` "----------------------Importing data files of the ${table_name} table----------------------"
      # You can also modify the following statement to use other data loading methods.

      # Note: The data files must be stored on the test server of seekdb.
      echo "load data /*+ parallel(80) direct(true,0) */ infile '${table_files_comma_separated}' into table ${table_name} fields terminated by '|';" | ${mysql_conn}
      }

   starttime=`date +%s%N`

   for table in "nation" "region" "customer" "lineitem" "orders" "partsupp" "part" "supplier"
   do
   load_data "${table}"
      done
   end_time=`date +%s%N`
   totaltime=`echo ${end_time} ${starttime} | awk '{printf "%0.2f\n", ($1 - $2) / 1000000000}'`
   echo `date "+[%Y-%m-%d %H:%M:%S]"` "load data cost ${totaltime}s"
   ```

   ### Step 8: Execute the test

You can generate a script based on the data and SQL statements described in the preceding steps. Here is an example of how to execute the test:

1. Write a test script named `tpch.sh`.

```bash

   #!/bin/bash
   host='$host_ip'   # Note: Please fill in the IP address of the server where seekdb is located.
   port='$host_port' # The port number of seekdb.
   user='$user'      # The username.
   password='$password'   # The password.
   database='$db_name'    # The database name.
   if [[ ${password} == "" ]];then
   TPCH_TEST="mysql -h${host} -P${port} -u${user} -D${database} -A -c"
   else
   TPCH_TEST="mysql -h${host} -P${port} -p${password} -u${user} -D${database} -A -c"
   fi
   function do_explain

   {
   # Execute the query plan.
   echo `date  '+[%Y-%m-%d %H:%M:%S]'` "BEGIN EXPLAIN ALL TPCH PLAN"
   for i in {1..22}
   do
   sql_explain="source explain_mysql/${i}.sql"
      echo `date  '+[%Y-%m-%d %H:%M:%S]'` "BEGIN EXPLAIN Q${i}:"
      echo ${sql_explain} | ${TPCH_TEST} | sed 's/\\n/\n/g' |tee explain_log/${i}.exp
      echo `date  '+[%Y-%m-%d %H:%M:%S]'` "Q${i} END"
      done
   }
   function do_warmup

   {
   # Warm up.
   totaltime=0
   for i in {1..22}
   do
   starttime=`date +%s%N`
         echo `date  '+[%Y-%m-%d %H:%M:%S]'` "BEGIN prewarm Q${i}"
         sql1="source mysql_sql/${i}.sql"
         echo ${sql1}| ${TPCH_TEST} > mysql_log/${i}_prewarm.log  || ret=1
         stoptime=`date +%s%N`
         costtime=`echo ${stoptime} ${starttime} | awk '{printf "%0.2f\n", ($1 - $2) / 1000000000}'`
         first_array[$i]=$(echo "scale=2; ${first_array[$i]} + $costtime" | bc)
         echo `date  '+[%Y-%m-%d %H:%M:%S]'` "END,COST ${costtime}s"
         totaltime=`echo ${totaltime} ${costtime} | awk '{printf "%0.2f\n", ($1 + $2)}'`
         done
   echo "total cost:${totaltime}s"
   }
   function hot_run

   {
   # Execute the query.
   for j in {1..2}
   do
   totaltime=0
   for i in {1..22}
   do
   starttime=`date +%s%N`
         echo `date  '+[%Y-%m-%d %H:%M:%S]'` "BEGIN BEST Q${i} (hot run)"
         sql1="source mysql_sql/${i}.sql"
         echo ${sql1}| ${TPCH_TEST} > mysql_log/${i}.log  || ret=1
         stoptime=`date +%s%N`
         costtime=`echo ${stoptime} ${starttime} | awk '{printf "%0.2f\n", ($1 - $2) / 1000000000}'`
         hot_array[$i]=$(echo "scale=2; ${hot_array[$i]} + $costtime" | bc)
         echo `date  '+[%Y-%m-%d %H:%M:%S]'` "END,COST ${costtime}s"
         totaltime=`echo ${totaltime} ${costtime} | awk '{printf "%0.2f\n", ($1 + $2)}'`
         done
   echo "total cost:${totaltime}s"
   done
   }
   do_explain

   do_warmup

   hot_run

   ```

   2. Run the test script.

```bash
   sh tpch.sh
   ```
