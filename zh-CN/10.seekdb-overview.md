# 了解 SeekDB

OceanBase SeekDB（简称 SeekDB）是 OceanBase 打造的一款开发者友好的新一代数据库产品，专注于为 AI 应用提供高效的混合搜索能力，支持向量、全文及多模数据的统一存储与检索。SeekDB 在继承 OceanBase 原核心引擎高性能优势与 MySQL 全面兼容特性的基础上，通过深度优化数据搜索架构，为开发者提供更符合 AI 应用数据处理需求的解决方案。

## 产品架构

![seekdb-arch](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/overview/seekdb-arch.png)

* 部署模式：支持 Client/Server 和嵌入式两种部署模式。嵌入式模式下可将 SeekDB 直接集成进 Python 应用，便于进行个人开发。
具有 ACID 事务语义的存储层：基于 LSM-Tree 架构的行存列存一体化存储引擎，自研高效的编码压缩机制降低存储成本。支持数据高频实时写入，和面向不同负载的高性能查询。

* 多模数据与索引层：支持基础类型，向量、大文本、JSON 、GIS、Array 等多模数据类型，并提供高效的索引支持。包括 HNSW/IVF 向量索引及索引量化算法，覆盖多种分词器和查询模式的基于 BM25 相关性计算算法的全文索引，适用于语义搜索的混合索引，及 JSON 多值索引、主键和二级索引、GIS 索引等。同时支持大宽表，以便减少关联计算，提升数据访问效率。

* 支持混合负载的多模计算层：支持向量、全文、标量等条件的混合搜索，提升 RAG 应用查询结果的准确性。提供 AI Function 能力，实现库内实时推理。支持完整的 ACID 事务特性及基于 MVCC 的多版本并发访问能力，提供高级查询优化器和具备向量化执行能力的高效执行引擎，以及灵活的 PL UDF，稳定支撑各类业务请求。

* 统一应用接口：兼容 MySQL 原生驱动，提供基于 SQL 的支持多模数据的统一查询语言。并在此基础上提供了面向开发者更加友好的向量库/混搜 SDK。同时适配近 30 种应用开发框架，也包含 LangChain、LlamaIndex、Dify 等 AI 应用开发框架。提供 MCP Server，无缝接入 AI 生态。

## 核心特性

### 极简部署，秒级初始化

单点架构，无需复杂配置，秒级即可完成初始化。支持 Client/Server 和嵌入式两种部署模式。Client/Server 部署模式下，支持 yum install、docker 或 windows/macos 桌面版部署方式；嵌入式部署模式下，原生 Python 集成，可作为 AI 应用内嵌数据库。

### 最低 1C1G 小规格，垂直弹性扩缩容

最低 1 核 CPU + 1GB 内存即可启动试用，向量搜索、混合搜索试用场景，建议内存不低于 4GB。对系统并发量、数据量、查询复杂度有较高要求时，可灵活垂直扩展资源规格。

### 高性能向量索引、全文索引，向量、全文、标量混合搜索

* 向量搜索

	支持高达 16,000 维向量存储与高性能检索，兼容 L2、内积、余弦相似度等多种距离计算方式，提供 HNSW/IVF 索引及相关量化算法，支持近似最近邻搜索，满足 AI 场景语义检索需求。

* 全文搜索

	支持高性能全文索引，基于 BM25 相关性排序算法，实现关键词精准搜索。支持 Space、Beng、Ngram、IK、Jieba 等多种分词器，提供 Natural Language Mode、Boolean Mode、Phrase Query、Multi Match 等多种查询模式，可在海量文本数据中快速定位目标信息，提升查询效率。

* 混合搜索

	支持向量、全文、标量、空间等多类数据的混合搜索，一条 SQL 完成多路查询与重排序。
  
同时 SeekDB 还提供了 Hybrid Index 功能，只需写入文本数据，系统自动进行 Embedding 并生成向量索引，查询时也仅需指定文本搜索条件，即可进行语义搜索。满足 RAG 技术方案下对多模数据混合查询的需求，助力企业构建高效智能的数据检索系统。

支持 SQL、Python SDK、Java SDK 多种访问接口，适用于各种应用开发环境。

### 无缝对接各类模型，内置 AI Function 实现库内实时推理

SeekDB 支持 Chat Model、Embedding Model 接入，提供 DBMS_AI_SERVICE 系统包，来管理 AI 模型信息。内置 AI_COMPLETE、AI_EMBED、AI_RERANK 等 AI Function，基于 SQL 表达式即可在数据库内进行 AI 数据处理和实时推理。

### 基于 JSON 的动态 Schema，支持文档元数据动态存储和高效访问。

SeekDB 支持 JSON 数据类型，具备动态 Schema 能力。支持 JSON 部分更新降低数据更新成本，并提供 JSON 函数索引、多值索引优化查询性能。实现半结构化编码，降低存储成本。在 AI 应用中，JSON 可作为文档元信息的存储类型，并支持和全文、向量的混合搜索能力。

### 数据实时写入，实时可查

基于 LSM-Tree 存储架构，SeekDB 支持数据的高频实时写入。数据 DML 时同步构建全文、向量、标量等各类索引，数据入库成功立即可查。

### 兼容 MySQL 不止于 MySQL，支撑 HTAP 混合负载 

高度兼容 MySQL 的语法、协议、视图等，但比 MySQL 提供了面向更广阔场景的计算和存储引擎的支持。基于行列混存技术、向量化执行能力，一个实例可以同时支持联机交易和实时分析等多种负载，省去数据同步的时间延迟和同步链路的维护成本。

## 应用场景

### RAG 应用

面向以智能客服、知识库、智能推荐为代表的 RAG 场景，SeekDB 支持了完整的 RAG Pipeline 解决方案。内置文档解析处理功能，集成 Embedding/Rerank/大语言模型，支持向量/全文/标量混合搜索，在一个数据库实例内实现 Doc In Data Out。

### AI 辅助编程

面向 AI 辅助编程和 AI Agent 开发场景，SeekDB 提供了快速启动和嵌入式部署能力，支持作为底层 Tool 被快速拉起提供服务。支持高频增删改和实时查询，避免数据库性能瓶颈引起 AI 开发效率降低的问题。提供全文索引功能，精准查询代码关键词。提供 MCP Server，无缝接入 AI 生态。

### MySQL 应用现代化和 AI 化升级

SeekDB 继承了 OceanBase 单机存储引擎、执行引擎、事务引擎、高级查询优化器的完整能力，高度兼容 MySQL。小规格可用于物联网边缘设备数据采集、小型应用开发和实验教学等场景。中大规格可用于各行业 OLTP、HTAP 的业务场景。

## FAQs

* Q：SeekDB 和 OceanBase 数据库单机版（Standalone）的区别是什么？

	A：OceanBase 数据库单机版是面向企业用户、包含分布式版本全量功能的一款单节点数据库产品，适用于非核心业务或中小体量业务，并提供平滑扩展为分布式版本的能力。SeekDB 是一款面向生态、门槛更低的新的数据库产品，去除多租户、分布式处理、Oracle 兼容等复杂特性，在 MySQL 兼容形态上快速迭代 DB4AI 能力。

* Q：是否支持从 SeekDB 升级到 OceanBase 数据库？

	A：不支持直接升级，但可以从 SeekDB 逻辑迁移到 OceanBase 数据库。
  
* Q：SeekDB 和 OceanBase 数据库的演进策略是什么？

	A：SeekDB 基于 OceanBase 数据库 V4.3.5 发展而来，包含 OceanBase 数据库 V4.3.5 的绝大部分功能。目前两者会单独演进，AI 相关的特性在 SeekDB 可以更快迭代，最终也会在 OceanBase 上提供支持。
