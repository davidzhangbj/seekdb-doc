# 部署流程

本节主要介绍 OceanBase 单机版的部署流程。

1. 部署前准备

	1. 准备服务器

        使用不同的部署方式以及选择不同的部署形态时，所需的服务器数量和规格有所不同，此外部署前需要检查服务器的软硬件配置。详细信息参见 [准备服务器](300.preparations-before-deploy/100.prepare-servers.md)。
  
	2. 准备安装包

        使用不同的部署工具以及选择不同的部署形态时，需要的安装包会有所不同，详细信息参见 [准备安装包](300.preparations-before-deploy/300.prepare-installation-packages.md)。

        <main id="notice" type='explain'>
           <h4>说明</h4>
           <p>OceanBase 单机版安装包暂未开放下载渠道，可联系 OceanBase 获取。</p>
        </main>

2. 完成部署前配置

    开始部署前，请根据 [部署前配置](500.environment-and-configuration-checks/200.use-ssh-to-log-on-without-password.md) 章节的内容进行检查并完成必要的部署前配置。   
     
3. 部署单机版

    可以通过以下几种方式来部署 OceanBase 数据库单机版。

    * [使用 obd 部署 OceanBase 数据库单机版](600.deploy-standalone-version/600.interactive-installation-of-ob.md)
        
        可以根据实际情况选择通过交互式部署单机版或者通过 yaml 配置文件部署单机版。

    * [使用 OCP 部署 OceanBase 数据库单机版](600.deploy-standalone-version/900.stand-alone-deployment-of-oceanbase-database-use-ocp.md)
