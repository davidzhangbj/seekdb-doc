# 部署概述

OceanBase SeekDB（简称 SeekDB）是 OceanBase 打造的一款开发者友好的新一代数据库产品，专注于为 AI 应用提供高效的混合搜索能力，支持向量、全文及多模数据的统一存储与检索。SeekDB 在继承 OceanBase 原核心引擎高性能优势与 MySQL 全面兼容特性的基础上，通过深度优化数据搜索架构，为开发者提供更符合 AI 应用数据处理需求的解决方案。

SeekDB 提供两种部署模式：

* 嵌入式模式：SeekDB 提供了嵌入式产品形态，支持以库的形式集成在用户的应用程序中，用户可以通过 python 脚本、API 接口方式访问 SeekDB，同时进行 SeekDB 的管理，维护，以及操作。

* 服务器模式：SeekDB 通过安装包及镜像的方式提供部署方法，用户可以把 SeekDB 安装在本地服务器上，通过 mysql 或 obclient 连接，可以让用户与正常数据库一样进行管理，维护。
