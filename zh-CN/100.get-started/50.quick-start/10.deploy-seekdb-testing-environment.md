# 快速部署 seekdb 体验环境

seekdb 提供了两种部署模式，嵌入式和服务器模式，您可以根据业务场景需要选择合适的部署模式。本文介绍如何快速部署嵌入式和服务器模式的 seekdb 体验环境。

:::info
  关于 seekdb 更详细和更全面的部署方式，参见 <a href="../../400.guides/400.deploy/50.deploy-overview.md">部署概述</a>。
:::

## 嵌入式模式

请确保您的环境需要满足以下要求：

* 操作系统：Linux（glibc >= 2.28)
* Python 版本：Python 3.8 ~ 3.14
* 系统架构：x86_64，aarch64
* 如果在部署时提示 pip 版本过低，请先升级 pip 后再安装：

  ```bash
  pip install --upgrade pip
  ```

### （推荐）使用 pyseekdb 部署

pyseekdb 是 seekdb 提供的 Python SDK。

使用 pip 安装，会自动加载嵌入式 seekdb。具体命令如下。


```shell
pip install pyseekdb
```

### 使用 Python 部署

使用 pip 安装，会自动识别默认的 Python 版本和平台。

```python
pip install pylibseekdb
# 或指定安装源加速
pip install pylibseekdb -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 服务器模式

### 前提条件

开始部署前，您需确认环境满足以下要求：

* 您使用的环境是 RPM 平台系统，目前已验证支持的系统如下。
  
  * Anolis OS 8.X 版本（内核 Linux 3.10.0 版本及以上）
  * Alibaba Cloud Linux 2/3 版本（内核 Linux 3.10.0 版本及以上）
  * Red Hat Enterprise Linux Server 7.X 版本、8.X 版本（内核 Linux 3.10.0 版本及以上）
  * CentOS Linux 7.X 版本、8.X 版本（内核 Linux 3.10.0 版本及以上）
  * Debian 9.X 版本及以上版本（内核 Linux 3.10.0 版本及以上）
  * Ubuntu 20.X 版本及以上版本（内核 Linux 3.10.0 版本及以上）
  * SUSE / OpenSUSE 15.X 版本及以上版本（内核 Linux 3.10.0 版本及以上）
  * openEuler 22.03 和 24.03 版本（内核 Linux 5.10.0 版本及以上）
  * KylinOS V10 版本
  * 统信 UOS 1020a/1021a/1021e/1001c 版本
  * 中科方德 NFSChina 4.0 版本及以上
  * 浪潮 Inspur kos 5.8 版本

* 当前环境中 CPU 最低要求 1 核。

* 当前环境中的可用内存最低要求 2G。
  
* 您环境中已安装数据库连接工具（MySQL 客户端或 OBClient 客户端）。

* 您使用的用户已具有执行 sudo 命令的权限。

* 使用 yum install 部署需要的条件
  
  * 您环境中已安装 jq 命令行工具，并正确配置了 systemd 作为系统和服务管理器。

* 使用 docker 部署需要的条件
  
  * 您已安装 Docker 并启动 Docker 服务。
  
### 使用 yum install 快速部署 seekdb

1. 添加 seekdb 镜像源。
    
    ```shell
    [admin@test001 ~]$ sudo yum-config-manager --add-repo https://mirrors.aliyun.com/oceanbase/OceanBase.repo
    ```

2. 安装 seekdb。
   
    ```shell
    [admin@test001 ~]$ sudo yum install seekdb obclient
    ```

3. 启动 seekdb。

    ```shell
    [admin@test001 ~]$ sudo systemctl start seekdb
    ```

4. 查看 seekdb 的启动状态。
   
    ```shell
    [admin@test001 ~]$ sudo systemctl status seekdb
    ```
    
    当状态显示为 `Service is ready` 时，表示 seekdb 已正常启动。

5. 连接 seekdb。

    ```shell
    mysql -h127.0.0.1 -uroot -P2881 -A oceanbase
    ```

### 使用容器环境快速部署 seekdb

如果您的环境中已安装 Docker 并启动 Docker 服务，也可以使用 Docker 容器部署 seekdb。有关 docker 部署的详细信息，请参考 [部署 seekdb 容器环境](../../400.guides/400.deploy/700.server-mode/200.deploy-by-docker.md)。

1. 直接启动 seekdb 实例。
    
    ```shell
    [admin@test001 ~]$ sudo docker run -d -p 2881:2881 oceanbase/seekdb
    ```
    :::info
      若拉取 Docker 镜像失败，您也可从 quay.io 或者 ghcr.io 仓库中拉取镜像，只需将上述拉取命令中的 <code>oceanbase/seekdb</code> 对应替换为 <code>quay.io/oceanbase/seekdb</code> 或 <code>ghcr.io/oceanbase/seekdb</code>，如执行 <code>sudo docker run -d -p 2881:2881 quay.io/oceanbase/seekdb</code> 从 quay.io 中拉取镜像。
    :::

2. 连接 seekdb。

    ```shell
    mysql -h127.0.0.1 -uroot -P2881 -A oceanbase
    ```
