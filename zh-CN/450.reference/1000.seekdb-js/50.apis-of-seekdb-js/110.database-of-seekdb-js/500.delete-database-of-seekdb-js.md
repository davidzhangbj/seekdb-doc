# deleteDatabase - 删除数据库

`deleteDatabase()` 用于删除一个数据库。

:::info

仅支持在使用 `SeekdbAdminClient` 连接时，才能使用该接口。关于 `SeekdbAdminClient` 的详细介绍，参见 [SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)。

:::

## 前提条件

* 您已经安装了 seekdb-js，有关安装 seekdb-js 的详细信息，参见 [快速开始](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)。

* 您已经安装了 seekdb 服务器模式，有关安装 seekdb 服务器模式的详细信息，参见 [通过 yum install 部署 seekdb](../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)。

* 您已经连接到数据库。有关连接的详细操作参见 [SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)。

* 请确保连接的用户具备 `DROP` 权限。查看当前用户权限的相关操作请参见 [查看用户权限](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)。如果不具备该权限，请联系管理员为您授权，用户授权的相关操作请参见 [直接授予权限](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)。

## 请求参数

```js
deleteDatabase(name: string, tenant?: string)
```

|参数|取值类型|是否必选|描述|取值示例|
|---|---|---|---|---|
|`name`|string|必选|指定要删除的数据库的名称。|my_database|
|`tenant`|string|可选<ul><li>当使用服务器模式 seekdb 时，不需要填写该参数。</li><li>当使用 OceanBase 数据库时，该参数必选。默认值为 `sys`。</li></ul>|指定所删除的数据库归属的租户。|test_tenant|

## 请求示例

```js
import { SeekdbAdminClient } from "seekdb";

// 远程服务器模式 - 数据库管理 (SeekDB Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: ""
});

await admin.deleteDatabase("my_database");
```

## 返回参数

无
