# listDatabases - 获取数据库列表

`listDatabases()` 用于获取实例中的数据库列表。

:::info

仅支持在使用 `SeekdbAdminClient` 连接时，才能使用该接口。关于 `SeekdbAdminClient` 的详细介绍，参见 [SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)。

:::

## 前提条件

* 您已经安装了 seekdb-js，有关安装 seekdb-js 的详细信息，参见 [快速开始](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)。

* 您已经安装了 seekdb 服务器模式，有关安装 seekdb 服务器模式的详细信息，参见 [通过 yum install 部署 seekdb](../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)。

* 您已经连接到数据库。有关连接的详细操作参见 [SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)。

## 请求参数

```python
listDatabases(limit?: number, offset?: number, tenant?: string)
```

|参数|取值类型|是否必选|描述|取值示例|
|---|---|---|---|---|
|`limit`|number|可选| 返回结果数量限制 |2|
|`offset`|number|可选| 结果偏移量 | 3|
|`tenant`|string|可选<ul><li>当使用服务器模式 seekdb 时，不需要填写该参数。</li><li>当使用 OceanBase 数据库时，该参数必选。默认值为 `sys`。</li></ul>|指定所查询的数据库归属的租户。|test_tenant|

:::tip

limit 和 offset 必须是非负整数。

:::

## 请求示例

```python
import { SeekdbAdminClient } from "seekdb";

// 远程服务器模式 - 数据库管理 (SeekDB Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: ""
});

// 列出所有数据库
const databases = await admin.listDatabases();

```

## 返回参数

|参数|返回类型|是否必选|描述|返回示例|
|---|---|---|---|---|
|`name`|string|必选|所查询的数据库的名称。|`my_database`|
|`tenant`|string|可选|所查询的数据库归属的租户。|`sys`|
|`charset`|string|可选|所查询的数据库使用的字符集。|`utf8mb4`|
|`collation`|string|可选|所查询的数据库使用的的排序方式。|`utf8mb4_general_ci`|
|`metadata`|dict|可选|预留字段，暂无数据| {} |
