# countCollection - 统计 Collections 数量

`countCollection()` 用于统计数据库中的 Collection 数量。

:::info

仅支持在使用 SeekdbClient 连接时，才能使用该接口。关于 SeekdbClient 的详细介绍，参见 [SeekdbClient](../50.seekdbclient-of-seekdb-js.md)。

:::

## 前提条件

* 您已经安装了 seekdb-js，有关安装 seekdb-js 的详细信息，参见 [快速开始](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)。

* 您已经安装了 seekdb 服务器模式，有关安装 seekdb 服务器模式的详细信息，参见 [通过 yum install 部署 seekdb](../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)。

* 您已经连接到数据库。有关连接的详细操作参见 [SeekdbClient](../50.seekdbclient-of-seekdb-js.md)。

* 您获取的 Collection 存在。如果 Collection 不存在，则会提示报错。

## 请求参数

```js
countCollection()
```

## 请求示例

```js
import { SeekdbClient } from "seekdb";

// 1. Connect
const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const count = await client.countCollection();
console.log(count);
```

## 返回参数

无

## 返回示例

```js
2
```
