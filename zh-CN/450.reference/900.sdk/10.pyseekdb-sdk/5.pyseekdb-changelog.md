# pyseekdb 更新记录

## pyseekdb V1.1.0 版本

* 发布日期：2026 年 1 月 30 日
* 版本号：V1.1.0

### 版本亮点

* Collection 命名更加灵活：名称长度上限从 64 字符提升至 **512 字符**，满足更复杂的业务场景。
* 全文检索能力增强：新增 `FulltextIndexConfig`，支持自定义分词器与字段映射。
* Embedding 生态大幅扩展：集成 **11 种**主流 embedding 平台，覆盖开源与商用模型。
* 元数据持久化升级：embedding 函数信息可持久化到系统表，进一步提升开发者使用便捷度。
* 新增 table-fork 能力（实验特性）：支持 Collection 级别的快照复制，简化数据实验与回滚。

### 新增功能

#### Collection 命名长度扩展

* 限制放宽：collection 名称支持 **64 ~ 512 字符**，适配更长的业务命名规范。
* 兼容性：旧版本创建的短名称 collection 不受影响。

#### 全文检索配置（FulltextIndexConfig）

* 新增配置结构：`create_collect/get_or_create_collection` 接口可以通过 configuration 参数除了可以制定 HNSW 索引配置，现在还可以定制全文索引配置。
* 官方文档参考：[全文索引配置指南](https://www.oceanbase.ai/docs/zh-CN/select-vector-index)。

#### Embedding 函数生态扩展

* 集成 11 种 embedding 函数**，覆盖以下平台：

    * 开源模型：`sentence-transformers`。
    * 商用服务：OpenAI, Azure, AWS Bedrock 等。
    * 所有集成的平台，[嵌入函数](60.embedding-funcations/50.ef-overview-py.md)。

#### Table-Fork 功能（实验特性）

:::tip
在 seekdb V1.1.0 版本中，Fork Table（复制 Collection）为实验特性，请谨慎用于生产环境。将在后续版本中继续完善为正式生产特性。
:::

* 快速创建 collection 快照。
* 使用场景：
    * A/B 测试不同索引参数
    * 数据回滚与灾难恢复
    * 更多适用场景，参见 [Fork 表](../../../200.develop/200.design-database-schema/50.fork-table.md)。
* 性能影响：fork 操作基于底层存储的 **写时复制（COW）**，耗时 < 1 秒（与数据量无关）。
