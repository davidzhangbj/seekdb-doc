# fork - 复制 Collection

`fork()` 用于复制指定的 Collection，以创建具有相同数据的新 Collection。

:::info

* 仅支持在使用 Client 连接时，才能使用该接口。关于 Client 的详细介绍，参见 [Client](../50.client.md)。

* 支持 seekdb 嵌入式和服务端模式 V1.1.0 版本以上。OceanBase 当前不支持。

:::

## 前提条件

* 您已经安装了 pyseekdb，有关安装 pyseekdb 的详细信息，参见 [快速开始](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)。

* 您已经连接到数据库。有关连接的详细操作参见 [Client](../50.client.md)。
  
* 您所需要复制的 Collection 存在。如果 Collection 不存在，则会提示报错。
  
## 请求参数

```python
fork(name)
```

|参数|取值类型|是否必选|描述|取值示例|
|---|---|---|---|---|
|`name`|string|必选|新的 Collection 的名称。|`my_collection_backup`|

## 请求示例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

# Delete a collection
original = client.get_collection("my_collection")
forked = original.fork("my_collection_backup")
```

## 返回参数

无
