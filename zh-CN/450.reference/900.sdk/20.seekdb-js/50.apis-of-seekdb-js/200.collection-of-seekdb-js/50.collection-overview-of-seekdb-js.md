# collection 管理

collection 在 seekdb-js 中为一种集合，类似与数据库中的表，用户可以进行创建、查询、删除对应的集合。

对于 collection 的操作，支持使用以下 API 接口。

| API 接口|描述     |相关文档链接|
|---|---|---|
| `createCollection()` | 创建 collection。 | [文档](100.create-collection-of-seekdb-js.md) |
| `getCollection()` | 获取指定 collection。 |[文档](200.get-collection-of-seekdb-js.md)|
| `getOrCreateCollection()` | 创建或者查询 Collection，如果数据库中 Collection 不存在，则创建；如果存在 Collection，则获取相应的结果。 |[文档](250.get-or-create-collection-of-seekdb-js.md)|
| `listCollections()`  | 获取数据库 collection 列表。  |[文档](300.list-collection-of-seekdb-js.md)|
| `countCollection()`  | 统计数据库中的 Collection 数量  |[文档](350.count-collection-of-seekdb-js.md)|
| `hasCollection()`  | 检查指定的 Collection 在数据库中是否存在  |[文档](360.hascollection-collection-of-seekdb-js.md)|
| `deleteCollection()`  | 删除指定 collection。|[文档](400.delete-collection-of-seekdb-js.md)|
