# API 参考

seekdb 支持通过 API 以编程的方式来使用 seekdb。

## API 接口

目前支持以下 API 接口。

### Database

:::info
仅支持在使用 `SeekdbAdminClient` 连接时，才能使用该接口。关于 `SeekdbAdminClient` 的详细介绍，参见 [SeekdbAdminClient](100.seekdbadminclient-of-seekdb-js.md)。
:::

| API 接口|描述     |相关文档链接|
|---|---|---|
| `createDatabase()` | 创建数据库。 | [文档](110.database-of-seekdb-js/200.create-database-of-seekdb-js.md) |
| `getDatabase()` | 获取指定数据库。 |[文档](110.database-of-seekdb-js/300.get-database-of-seekdb-js.md)|
| `listDatabases()`  | 获取实例中数据库列表。  |[文档](110.database-of-seekdb-js/400.list-database-of-seekdb-js.md)|
| `deleteDatabase()`  | 删除指定数据库。|[文档](110.database-of-seekdb-js/500.delete-database-of-seekdb-js.md)|

### Collection

:::info
仅支持在使用 SeekdbClient 连接时，才能使用该接口。关于 SeekdbClient 的详细介绍，参见 [SeekdbClient](50.seekdbclient-of-seekdb-js.md)。
:::

| API 接口|描述     |相关文档链接|
|---|---|---|
| `createCollection()` | 创建 collection。 | [文档](200.collection-of-seekdb-js/100.create-collection-of-seekdb-js.md) |
| `getCollection()` | 获取指定 collection。 |[文档](200.collection-of-seekdb-js/200.get-collection-of-seekdb-js.md)|
| `getOrCreateCollection()` | 创建或者查询 Collection，如果数据库中 Collection 不存在，则创建；如果存在 Collection，则获取相应的结果。 |[文档](200.collection-of-seekdb-js/250.get-or-create-collection-of-seekdb-js.md)|
| `fork()` | 复制指定的 Collection，以创建具有相同数据的新 Collection。|[文档](200.collection-of-seekdb-js/260.fork-collection-of-seekdb-js.md)|
| `listCollections()`  | 获取数据库 collection 列表。  |[文档](200.collection-of-seekdb-js/300.list-collection-of-seekdb-js.md)|
| `countCollection()`  | 统计数据库中的 Collection 数量  |[文档](200.collection-of-seekdb-js/350.count-collection-of-seekdb-js.md)|
| `hasCollection()`  | 检查指定的 Collection 在数据库中是否存在  |[文档](200.collection-of-seekdb-js/360.hascollection-collection-of-seekdb-js.md)|
| `deleteCollection()`  | 删除指定 collection。|[文档](200.collection-of-seekdb-js/400.delete-collection-of-seekdb-js.md)|

### DML

:::info
仅支持在使用 SeekdbClient 连接时，才能使用该接口。关于 SeekdbClient 的详细介绍，参见 [SeekdbClient](50.seekdbclient-of-seekdb-js.md)。
:::

| API 接口|描述     |相关文档链接|
|---|---|---|
| `add()` | 将新记录插入到 collection 中。 | [文档](300.dml-of-seekdb-js/200.add-data-of-seekdb-js.md) |
| `update()` | 更新 collection 中的现有记录。 |[文档](300.dml-of-seekdb-js/300.update-data-of-seekdb-js.md)|
| `upsert()`  | 插入新记录或更新现有记录。  |[文档](300.dml-of-seekdb-js/400.upsert-data-of-seekdb-js.md)|
| `delete()`  | 从 collection 中删除记录。|[文档](300.dml-of-seekdb-js/500.delete-data-of-seekdb-js.md)|

### DQL

:::info
仅支持在使用 SeekdbClient 连接时，才能使用该接口。关于 SeekdbClient 的详细介绍，参见 [SeekdbClient](50.seekdbclient-of-seekdb-js.md)。
:::

| API 接口|描述     |相关文档链接|
|---|---|---|
| `query()` | 向量相似度搜索方法。 | [文档](400.dql-of-seekdb-js/200.query-interfaces-of-seekdb-js.md) |
| `get()` | 使用 ID、document 和 metadata（非矢量）从表中查询特定数据。 |[文档](400.dql-of-seekdb-js/300.get-interfaces-of-seekdb-js.md)|
| `hybridSearch()`  | 全文搜索和向量相似度搜索，采用排名法。  |[文档](400.dql-of-seekdb-js/400.hybrid-search-of-seekdb-js.md)|
