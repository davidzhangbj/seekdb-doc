# 创建自定义嵌入函数

您可以通过实现 IEmbeddingFunction 接口创建自定义向量函数。该函数必须包含以下内容:

* 实现 `generate` 方法,接受 `string[]` 并返回 `Promise<number[][]>`。
* 可选实现其他接口方法

:::tip

`registerEmbeddingFunction` API `getEmbeddingFunction` 目前处于实验阶段。

:::

## 前提条件

创建自定义嵌入函数时，请确保以下内容：

* 实现 `generate` 方法：
  
  * 接受: `string[]` (文档列表)。
  * 返回: `Promise<number[][]>` (向量列表)。
  * 每个向量必须具有相同的维度。

* 处理边缘情况:
  
  * 空输入应返回空列表。
  * 输出中的所有向量必须具有相同的维度。

* 可选方法 (实现以增强功能):
  
  * `generateForQueries?()`: 为查询生成向量 (可以与文档向量不同)。
  * `name?`: 向量函数名称。
  * `defaultSpace?()`: 默认向量空间。
  * `supportedSpaces?()`: 支持的向量空间列表。

## 示例1：句子转换器自定义嵌入功能

```python
import type { IEmbeddingFunction } from "seekdb";

class MyCustomEmbeddingFunction implements IEmbeddingFunction {
  private modelName: string;
  private _dimension: number;

  constructor(modelName: string = "my-model") {
    this.modelName = modelName;
    this._dimension = 384; // 您的模型维度
  }

  async generate(texts: string[]): Promise<number[][]> {
    // 实现您的向量生成逻辑
    // 例如,调用外部 API 或本地模型
    const embeddings: number[][] = [];
    
    for (const text of texts) {
      // 您的向量生成代码
      const embedding = await this.generateSingleEmbedding(text);
      embeddings.push(embedding);
    }
    
    return embeddings;
  }

  private async generateSingleEmbedding(text: string): Promise<number[]> {
    // 实现单个文本的向量生成
    // 返回一个长度为 this._dimension 的数组
    return new Array(this._dimension).fill(0).map(() => Math.random());
  }
}

// 使用自定义向量函数
const customEmbed = new MyCustomEmbeddingFunction("my-model");

const collection = await client.createCollection({
  name: "custom_embed_collection",
  configuration: {
    dimension: 384,
    distance: "cosine"
  },
  embeddingFunction: customEmbed
});
```
