# Qwen 向量函数

使用 DashScope 的云向量服务 (Qwen/通义千问)。适合生产环境。

:::tip

`QwenEmbeddingFunction` 目前为实验性功能。

:::

在首次使用时需要先安装，命令如下：

```shell
npm install @seekdb/qwen
```

在项目中实例化并使用模型:

```js
import { QwenEmbeddingFunction } from "@seekdb/qwen";

const qwenEmbed = new QwenEmbeddingFunction({
  // 您的 DashScope API Key,默认从环境变量读取
  apiKey: "sk-...",
  // 可选,默认为 text-embedding-v4
  modelName: "text-embedding-v4"
});

const collection = await client.createCollection({
  name: "qwen_embed_collection",
  embeddingFunction: qwenEmbed
});
```
