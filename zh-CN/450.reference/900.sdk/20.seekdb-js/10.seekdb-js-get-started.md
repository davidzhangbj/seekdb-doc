# 快速开始

## seekdb-js 

seekdb-js 是 OceanBase 提供的 node 客户端。实现了基于一套 API 接口，支持连接到远程服务器（支持服务器模式的 seekdb 和 OceanBase 数据库）。

:::tip
OceanBase 数据库是 OceanBase 提供的一款完全自研的企业级原生分布式数据库，在普通硬件上实现金融级高可用，首创“三地五中心”城市级故障自动无损容灾新标准，刷新 TPC-C 标准测试，单集群规模超过 1500 节点，具有云原生、强一致性、高度兼容 Oracle/MySQL 等特性。有关 OceanBase 数据库的更多信息，参见 [OceanBase 数据库](https://www.oceanbase.com/docs/oceanbase-database-cn)。
:::

## 安装 seekdb-js

### 前提条件

请确保您的环境需要满足以下要求：

* Node.js 版本：Node.js 20 及之后版本

* 已部署完成 seekdb 服务器模式，并已启动，有关 seekdb 的详细部署，请参考 [通过 yum install 部署 seekdb](../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)。

### 安装

```shell
npm install seekdb
```
