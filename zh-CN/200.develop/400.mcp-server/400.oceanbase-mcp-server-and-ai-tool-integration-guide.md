# seekdb MCP Server

## 概述

seekdb MCP Server 是一个基于 Model Context Protocol (MCP) 协议的服务器，让你可以在支持 MCP 的 AI 编程工具（如 Cursor、Windsurf、Cline 等）中，通过自然语言对话来操作 seekdb 向量数据库。

只需配置一条命令 `uvx seekdb-mcp-server`，即可启动服务，无需单独安装 seekdb 数据库，开箱即用。

:::tip

目前仅支持 Linux 平台（）。

:::

## 什么是 MCP？

MCP (Model Context Protocol) 是 Anthropic 在 2024 年 11 月推出的开源协议，让大语言模型能够与外部工具和数据源进行交互。

MCP 协议弥合了 AI 工具与数据之间的鸿沟，让 AI 助手能够直接访问数据库、执行命令。

## 功能架构

seekdb MCP Server 提供标准化接口，支持 AI 工具直接调用数据库功能：

* 向量集合工具

    |            工具名称          | 功能说明 |
    |-----------------------------|----------|
    | `create_collection`         | 创建具有可配置维度和距离度量的新向量集合 |
    | `list_collections`         | 列出 seekdb 中的所有集 |
    | `has_collection`          | 检查集合是否存在|
    | `add_data_to_collection`     | 预览集合中的文档 |
    | `update_collection`   | 更新集合中的现有文档 |
    | `delete_documents`   `| 按 ID 或过滤条件删除文档 |
    | `query_collection`           | 使用向量相似性搜索查询文档 |
    | `delete_collection`          | 删除集合及其所有数据 |

* 搜索工具

    |            工具名称          | 功能说明 |
    |-----------------------------|----------|
    | `full_text_search`         |使用 MATCH...AGAINST 语法执行全文搜索 |
    | `hybrid_search`         | 结合全文搜索和向量搜索，使用 RRF 排序 |

* AI 模型工具

    |            工具名称          | 功能说明 |
    |-----------------------------|----------|
    | `create_ai_model`    | 注册 AI 模型（嵌入、文本生成或重排序）|
    | `create_ai_model_endpoint`   | 创建将模型连接到 API 服务的端点 |
    | `drop_ai_model`         | 移除已注册的 AI 模型 |
    | `drop_ai_model_endpoint`         | 移除 AI 模型端点 |
    | `ai_complete`         | 调用 LLM 进行文本生成 |
    | `ai_rerank`         | 使用 AI 模型按相关性重排文档 |
    | `get_registered_ai_models`         | 列出所有已注册的 AI 模型 |
    | `hybrid_search`         | 列出所有 AI 模型端点  |


* 记忆工具

    |            工具名称          | 功能说明 |
    |-----------------------------|----------|
    | `seekdb_memory_query`    | 注册 AI 模型（嵌入、文本生成或重排序）|
    | `seekdb_memory_insert`   | 创建将模型连接到 API 服务的端点 |
    | `seekdb_memory_delete`         | 移除已注册的 AI 模型 |
    | `seekdb_memory_update`         | 调用 LLM 进行文本生成 |

* 数据导入/导出工具

    |            工具名称          | 功能说明 |
    |-----------------------------|----------|
    | `import_csv_file_to_seekdb`    | 将 CSV 数据导入为表或向量集合|
    | `seekdb_memory_iexport_csv_file_from_seekdbnsert`   | 将表或集合数据导出为 CSV |

* 数据库工具

    |            工具名称          | 功能说明 |
    |-----------------------------|----------|
    | `execute_sql`    | 在 seekdb 上执行 SQL 查询|
    | `get_current_time`   | 从 seekdb 数据库获取当前时间 

## 前提条件

* 您已安装 Cursor 或其他支持 MCP 协议的工具（如 Windsurf、Qwen Code）。
* 您已完成部署 seekdb。
  
  * 有关部署 seekdb 的信息，参见 [部署 seekdb](../../400.guides/400.deploy/100.prepare-servers.md)。

* 您已安装 Python 环境（版本 3.10 ~ 3.12）。

  * Python 安装包可在 [Python 官方网站](https://www.python.org/downloads/) 下载。

* glibc >= 2.28
* 系统为 linux x86_64 或者 aarch64 架构

## 快速开始

### 步骤一：安装 uv

uv 是一个 Python 包管理器，uvx 命令可以直接运行 Python 工具。

```sql
# Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# 或者通过 pip 安装
pip install uv
```

安装完成后，运行 `source ~/.bashrc` 确保 uvx 命令可用。

### 步骤二： 配置 AI 编程工具

本文以 Cursor 为例：

1. 进入 Cursor 设置页面：点击右上角齿轮图标 → 选择 MCP → 点击 New MCP Server。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.4.1/690.practical-tutorial/900.oceanbase-mcp-server-ai/1.0.png)

2. 编辑 `mcp.json` 配置。

    ```shell
    {
      "mcpServers": {
        "seekdb": {
          "command": "uvx",
          "args": ["seekdb-mcp-server"]
        }
      }
    }
    ```

    如果遇到网络问题，可以配置使用阿里云镜像源：

    ```python
    {
    "mcpServers": {
        "seekdb": {
          "command": "uvx",
          "args": ["seekdb-mcp-server"],
          "env": {
            "UV_DEFAULT_INDEX": "https://mirrors.aliyun.com/pypi/simple/"
          }
        }
      }
    }
    ```

保存后，大约等待 1 分钟，Cursor 会自动启动 seekdb MCP Server。

:::tip

其他支持 MCP 的工具（Windsurf、Cline、Continue、Trae 等）配置方式类似。

:::

## 常见问题

**问题：** 需要安装 seekdb 吗？
**答：** 不需要！seekdb MCP Server 使用嵌入式模式，seekdb 已经包含在内，无需单独安装。

**问题：** 数据存储在哪里？
**答：** 数据存储在本地文件系统中，默认在当前用户家目录下。你的数据完全在本地，不会上传到任何云端。

**问题：** 支持哪些操作系统？
**答：** 目前支持 Linux（glibc >= 2.28），支持 x86_64 和 aarch64 架构。

**问题：** 如何升级？
**答：** 使用 uvx 时会自动使用最新版本。
