# 快速开始

## pyseekdb

pyseekdb 是 OceanBase 提供的 Python 客户端。实现了基于一套 API 接口，提供两种数据库连接模式。其适用于 Linux、macOS、Windows 系统。不同的操作系统，对应的情况如下：

| 系统 | 描述 |
| ---- | ------- |
| Linux | 安装时会同时安装嵌入式模式的 seekdb，可以直接连接到嵌入式 seekdb 执行创建数据库等操作。或者选择远程连接到已经部署好的服务器模式的 seekdb 或者 OceanBase 数据库。| 
| macOS | 安装时不会安装嵌入式模式的 seekdb，只支持连接到远程服务器（支持服务器模式的 seekdb 和 OceanBase 数据库）。|
| Windows | 安装时不会安装嵌入式模式的 seekdb，只支持连接到远程服务器（支持服务器模式的 seekdb 和 OceanBase 数据库）。|

## 安装 pyseekdb

### 前提条件 

请确保您的环境需要满足以下要求：

* 操作系统：Linux（glibc >= 2.28）、macOS、Windows
* Python 版本：Python 3.11 及之后版本
* 系统架构：x86_64，aarch64

### 安装

使用 pip 安装，会自动识别默认的 Python 版本和平台。

```shell
pip install pyseekdb
```

如果您的 pip 版本比较低，请先升级 pip 后再安装。

```bash
pip install --upgrade pip
```
