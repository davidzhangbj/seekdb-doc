# 快速部署 SeekDB 体验环境

本文以 yum install 和在 Docker 环境中使用为例介绍如何快速部署 SeekDB。

## 前提条件

在执行本文操作前，您需确认以下信息：

* 您使用的环境是 RPM 平台系统，目前已验证支持的系统如下。
  
  * Anolis OS 8.X 版本（内核 Linux 3.10.0 版本及以上）
  * Alibaba Cloud Linux 2/3 版本（内核 Linux 3.10.0 版本及以上）
  * Red Hat Enterprise Linux Server 7.X 版本、8.X 版本（内核 Linux 3.10.0 版本及以上）
  * CentOS Linux 7.X 版本、8.X 版本（内核 Linux 3.10.0 版本及以上）
  * Debian 9.X 版本及以上版本（内核 Linux 3.10.0 版本及以上）
  * Ubuntu 20.X 版本及以上版本（内核 Linux 3.10.0 版本及以上）
  * SUSE / OpenSUSE 15.X 版本及以上版本（内核 Linux 3.10.0 版本及以上）
  * openEuler 22.03 和 24.03 版本（内核 Linux 5.10.0 版本及以上）
  * KylinOS V10 版本
  * 统信 UOS 1020a/1021a/1021e/1001c 版本
  * 中科方德 NFSChina 4.0 版本及以上
  * 浪潮 Inspur kos 5.8 版本

* 当前环境中 CPU 最低要求 1 核。

* 当前环境中的可用内存最低要求 2G。

* 您环境中已安装 jq 命令行工具，并正确配置了 systemd 作为系统和服务管理器。

* 您环境中已安装数据库连接工具（MySQL 客户端或 OBClient 客户端）。

* 您使用的用户已具有执行 sudo 命令的权限。

## 快速部署 SeekDB

### 使用 yum install 快速部署 SeekDB

1. 添加 SeekDB 镜像源
    
    ```shell
    [admin@test001 ~]$ sudo yum-config-manager --add-repo https://mirrors.aliyun.com/oceanbase/OceanBase.repo
    ```

2. 安装 SeekDB
   
    ```shell
    [admin@test001 ~]$ sudo yum install oceanbase-seekdb obclient
    ```

3. 启动 SeekDB

    ```shell
    [admin@test001 ~]$ sudo systemctl start seekdb
    ```

4. 查看 SeekDB 的启动状态
   
    ```shell
    [admin@test001 ~]$ sudo systemctl status seekdb
    ```
    
    当状态显示为 `Service is ready` 时，表示 SeekDB 已正常启动。

5. 连接 SeekDB

    ```shell
    obclient -h127.0.0.1 -uroot -P2881 -A oceanbase
    ```

### 使用容器环境快速部署 SeekDB

如果您的环境中已安装 Docker 并启动 Docker 服务，也可以使用 Docker 容器部署 SeekDB。

1. 搜索 SeekDB 相关镜像
    
    ```shell
    [admin@test001 ~]$ sudo docker search seekdb
    ```


2. 拉取 SeekDB 最新镜像
  
    ```shell
    [admin@test001 ~]$ sudo docker pull oceanbase/seekdb
    ```

3. 启动 SeekDB 实例
    
    运行如下命令，启动 SeekDB 实例。
    
    ```shell
    [admin@test001 ~]$ sudo docker run -d --restart unless-stopped -p 2881:2881 --name obseekdb -v /home/admin/seekdb:/var/lib/oceanbase  oceanbase/seekdb
    ```

4. 连接 SeekDB 实例

    您可以使用宿主机本地 OBClient 或 MySQL 客户端连接到 SeekDB 实例。
   
    ```shell
    [admin@test001 ~]$ mysql -uroot -h127.0.0.1 -P2881 -p
    ```
