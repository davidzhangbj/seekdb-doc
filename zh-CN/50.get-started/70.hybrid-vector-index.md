# SeekDB 语义索引快速上手

本教程将引导您快速上手 SeekDB 语义索引，帮助您理解语义索引的实际应用，并在几分钟内体验语义索引的强大功能：无需手动转换为向量，直接存储文本即可实现语义检索。

## 概述

对比传统向量索引和语义索引：

传统：文本 → 手动 embedding → 向量 → 插入 → 检索
语义索引：文本 → 直接插入 → 直接文本检索
