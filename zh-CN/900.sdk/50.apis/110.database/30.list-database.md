# list_databases

`list_databases` 用于获取实例中所有的数据库。

:::info

仅支持在使用 `AdminClient` 连接时，才能使用该接口。关于 `AdminClient` 的详细介绍，参见 [Admin Client](../100.admin-collection.md)。

:::

## 请求参数

```python
list_databases(limit=None, offset=None, tenant=DEFAULT_TENANT)
```

|参数|取值类型|是否必选|描述|取值示例|
|---|---|---|---|---|
|`limit`|int|可选|返回数据库的最大数量。|1|
|`offset`|int|可选|Number of results to skip for pagination。||
|`tenant`|string|可选<ul><li>当使用嵌入式 seekdb 和服务器模式 seekdb 时，不需要填写该参数；如果填写了，会忽略。</li><li>当使用 OceanBase 数据库时，该参数必选。默认值为 `sys`。</li></ul>|指定所查询的数据库归属的租户。|test_tenant|

## 请求示例

```python
# Use context manager
with pyseekdb.AdminClient(host="127.0.0.1", port=2881, user="root") as admin:
    # List all databases
    databases = admin.list_databases()
    for db in databases:
        print(f"Database: {db.name}")
```

## 返回参数

|参数|返回类型|是否必选|描述|返回示例|
|---|---|---|---|---|
|`name`|string|必选|所查询的数据库的名称。|`my_database`|
|`tenant`|string|可选<br/>当使用嵌入式 seekdb 和服务器模式 SeekDB 时，没有该参数。|所查询的数据库归属的租户。|`test_tenant`|
|`charset`|string|可选|所查询的数据库使用的字符集。|`utf8mb4`|
|`collation`|string|可选|所查询的数据库使用的的排序方式。|`utf8mb4_general_ci`|
|`metadata`|dict|可选|预留字段，暂无数据| |


## 返回示例

```python
# List all databases
databases = admin.list_databases()
for db in databases:
    print(f"Database: {db1.name}, Charset: {db1.charset}, collation:{db1.collation}, metadata:{db1.metadata}")
```
