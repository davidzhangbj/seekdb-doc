# Client

`Client` 用于连接不同模式的数据库，嵌入式模式和服务器模式，会根据提供的参数自动选择合适的连接模式。

:::tip
OceanBase 数据库是 OceanBase 提供的一款完全自研的企业级原生分布式数据库，在普通硬件上实现金融级高可用，首创“三地五中心”城市级故障自动无损容灾新标准，刷新 TPC-C 标准测试，单集群规模超过 1500 节点，具有云原生、强一致性、高度兼容 Oracle/MySQL 等特性。有关 OceanBase 数据库的更多信息，参见 [OceanBase 数据库](https://www.oceanbase.com/docs/oceanbase-database-cn)。
:::

## 连接嵌入式 seekdb

通过 `Client` 连接到本地嵌入式 seekdb 实例。

示例如下：

```python
import pyseekdb

# Create embedded client
client = pyseekdb.Client(
    #path="./seekdb",      # Path to SeekDB data directory
    #database="test"        # Database name
)
```

参数说明：

|参数|描述|
|---|---|
|`path`|seekdb 数据目录的路径。seekdb 会在该路径下存储数据库文件并在启动时加载。|
|`database`|数据库名称。|

## 连接服务器模式

通过 `Client` 连接到服务器模式，支持连接到 seekdb 和 OceanBase 数据库。

> 连接之前，请确保您已经部署了客户端模式的 seekdb。有关客户端模式 seekdb 的部署方法，参见 []()。

示例如下：

```python
import pyseekdb

# Create server client
client = pyseekdb.Client(
    host="127.0.0.1",      # Server host
    port=2882,              # Server port (default: 2882)
    database="test",        # Database name
    user="root",            # Username (default: "root")
    password=""             # Password
)
```

参数说明：

|参数|描述|
|---|---|
|`host`|实例所在服务器 IP。|
|`prot`|实例端口。默认为 2882。|
|`database`|数据库名。|
|`user`|用户名。默认为 root。|
|`password`|用户所对应的密码。|


## 连接到 OceanBase 数据库

通过 Client 连接到 OceanBase 数据库。

示例如下：

```python
import pyseekdb

# Create OceanBase client
client = pyseekdb.OBClient(
    host="127.0.0.1",       # Server host
    port=11402,             # OceanBase port
    tenant="mysql",         # Tenant name
    database="test",        # Database name
    user="root",            # Username
    password=""             # Password
)
```

参数说明：

|参数|描述|
|---|---|
|`host`|数据库所在服务器 IP。|
|`prot`|OceanBase 数据库端口。|
|`tenant`|租户名。|
|`database`|数据库名。|
|`user`|租户对应的用户名。|
|`password`|用户所对应的密码。|

## 使用 Client 进行连接所支持的接口

当使用 `Client` 连接数据库时，支持使用以下 API 接口。

| API 接口|描述     |
|---|---|
| `execute(sql)`  | 执行 SQL 语句并返回 cursor 结果（如果需求，可以自动提交）。  |
| `is_connected()` | 检查指定的连接是否活跃。 |
| `mode` | 查询 client 类名，会返回具体的 client 类名，包含 `seekdbEmbeddedClient`、`seekdbServerClient`、`OceanBaseServerClient`。|
| `create_collection()` | 创建一个新的 collection。 |
| `get_collection()` | 查询指定的 collection。 |
| `delete_collection()`  | 删除指定的 collection。  |
| `list_collections()`  | 列出当前数据库中全部的 collections。|
| `has_collection()` | 检查指定的 collection 是否存在。|
| `get_or_create_collection()` | 查询指定的 collection，如果该 collection 不存在则会创建该 collection。|
| `count_collection()` | 查询当前数据库中所有 collection 的数量。 |
