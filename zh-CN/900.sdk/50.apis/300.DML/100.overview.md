# DML 操作

DML（数据操作语言）操作允许您在 collection 中插入、更新和删除数据。

其包含以下几种内容：

* add()：将新记录插入到 collection 中。有关其详细操作，请参考 [插入数据](200.add.md)。
* update()：更新 collection 中的现有记录。有关其详细操作，请参考 [更新数据](300.update.md)。
* upsert()：插入新记录或更新现有记录。有关其详细操作，请参考 [更新或插入数据](400.upsertmd)。
* delete()：从 collection 中删除记录。有关其详细操作，请参考 [删除数据](500.deleye.md)。
