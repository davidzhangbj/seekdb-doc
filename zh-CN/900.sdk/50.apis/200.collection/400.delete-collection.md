# 删除 Collections

`delete_collection` 用于删除指定的 Collection。

## 前提条件

* 您已部署 seekdb 或者嵌入式 seekdb。
* 您所需要删除的 Collection 存在。
  
## 请求参数

```python
client.delete_collection(name)
```

|参数|取值类型|是否必选|描述|取值示例|
|---|---|---|---|---|
|`name`|string|必选|指定要删除的 Collection 的名称。|my_collection|

## 请求示例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

# Delete a collection
client.delete_collection("my_collection")
```

## 返回参数

无
